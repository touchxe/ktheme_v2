# Receiving Code Review

## Stage 1: Spec Compliance
- Blocker → 즉시 수정
- Improvement → Stage 2
- Nice-to-have → 별도 task

## Stage 2: Code Quality
Naming, 중복 제거, 추출

## 원칙
모든 피드백에 응답 (수용/거부 + 이유). 방어 금지.
