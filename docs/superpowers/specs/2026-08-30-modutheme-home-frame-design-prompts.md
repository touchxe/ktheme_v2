# 모두테마 6종 홈 프레임 기획 명세

Date: 2026-08-30  
Status: ready for external design production

## Who

- 모두테마로 업종별 홈페이지를 빠르게 제작하는 운영자와 디자이너
- 방문 목적이 분명하지만 어떤 메뉴부터 선택해야 할지 모르는 최종 사용자
- Figma, Stitch, 이미지 생성 도구, 코드 생성 도구에 화면 제작을 요청하는 외부 제작 담당자

## What

61개 프리셋을 아래 여섯 행동형 홈 프레임으로 수렴한다.

1. 예약형: 날짜, 인원, 서비스, 담당자, 지점 선택을 시작하는 홈
2. 상담형: 문제, 신뢰, 담당 범위, 상담 채널을 확인하는 홈
3. 견적형: 요구사항, 기술 근거, 사례, 자료를 검토하고 견적을 요청하는 홈
4. 구매형: 상품, 가격, 옵션, 재고, 배송 정보를 탐색하고 구매하는 홈
5. 미디어/공동체형: 최근 콘텐츠, 모임 일정, 새 방문자 안내, 참여 경로를 찾는 홈
6. 기관/포털형: 공지, 사업, 일정, 자료, 소속기관을 업무 중심으로 찾는 홈

## Why

업종별로 개별 홈을 무한히 추가하는 대신 전환 행동이 같은 업종을 하나의 구조로 묶어 제작 비용을 줄인다. 동시에 카피와 이미지 교체만으로는 해결되지 않는 예약 상태, 민감정보 고지, 기술 사양, 재고, 라이브 미디어, 기관 검색의 구조 차이는 프레임 수준에서 보장한다.

## Success

- 여섯 프레임 모두 1440px 데스크톱과 390px 모바일 화면 제작 지시가 있다.
- 각 프레임에 목적, 사용자, 전환, 섹션 순서, 블록 상태, 모바일 규칙, 필수 상태 화면이 있다.
- 외부 디자인 도구에 단독으로 입력 가능한 완성형 프롬프트가 여섯 개 있다.
- 61개 프리셋이 기본 프레임 하나에 빠짐없이 배정된다.
- 현재 테마에서 재사용, 변형, 신규 제작할 블록이 구분된다.
- 모든 프레임이 `docs/DESIGN.md` 토큰과 금지 규칙을 따른다.

## Constraints

- 한 페이지는 하나의 밝은 화면 테마와 하나의 강조색 체계를 유지한다.
- 기본 콘텐츠 폭은 1200px, 넓은 화면 기준은 1440px, 모바일 기준은 390px이다.
- 상단 내비게이션은 한 줄, 높이 80px 이하로 유지한다.
- 히어로 제목은 두 줄 이하, 보조문장은 20단어 수준 이하, 주요 CTA는 첫 화면 안에 둔다.
- 3열 동일 아이콘 카드, 보라색 계열 그라디언트, 전 구간 중앙정렬, 과도한 둥근 모서리, 근거 없는 통계, 제네릭 히어로 문구를 사용하지 않는다.
- 카드보다 여백, 구분선, 타이포그래피를 우선한다.
- 목록, 예약, 폼, 상품, 미디어에 필요한 로딩, 빈 결과, 오류, 마감, 품절, 완료 상태를 함께 설계한다.
- 화면에 표시되는 문구에 긴 대시 문자를 쓰지 않는다.

## Out of scope

- 결제 모듈, 예약 엔진, 지도 API, 동영상 스트리밍의 실제 연동
- 개별 업체의 로고, 실주소, 실제 후기, 가격, 의료·법률 성과 수치 생성
- 하위 페이지 전체 시안 제작
- WordPress 템플릿 구현과 배포
