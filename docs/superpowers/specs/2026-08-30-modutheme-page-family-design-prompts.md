# 모두테마 15종 페이지군 디자인 프롬프트 명세

Date: 2026-08-30  
Status: ready for documentation production

## Who

- 모두테마의 업종별 데모 사이트와 프리셋을 기획하는 운영자
- Figma, Stitch, 이미지 기반 UI 도구, 코드 생성 AI에 화면 제작을 맡기는 디자이너
- 예약, 상담, 견적, 구매, 기관 탐색을 수행하는 최종 사용자

## What

다음 15개 페이지군을 외부 AI가 독립적으로 제작할 수 있도록 기본 기획과 완성형 프롬프트를 만든다.

1. 제품·서비스·프로그램 목록 및 상세
2. 전문가·의료진 개별 상세
3. 사례·프로젝트 목록 및 상세
4. 예약 가능 날짜·시간·정원 선택
5. 견적 및 파일 첨부 폼
6. 자가진단과 결과 화면
7. 제품·서비스·패키지 비교
8. 후기·UGC 및 전후 비교
9. 지점·매장·캠퍼스 찾기
10. 추천 코스·주변 지도
11. 평면·타입 뷰어
12. 인증·특허 라이브러리
13. 상품·장바구니·결제·계정
14. 목적별 상품 추천
15. 프로모션·세트·구독

15개 페이지군은 목록·상세·결과·계정 화면을 합쳐 총 27개 기본 화면 원형으로 구성한다. 각 원형은 1440px 데스크톱, 390px 모바일, 필수 상태 보드를 포함한다.

## Why

홈 화면 이후의 핵심 전환 페이지는 데이터 필드, 상태, 오류 처리, 모바일 전환 방식이 서로 다르다. 한 장짜리 미관 중심 프롬프트가 아니라 실제 콘텐츠와 운영 상태를 담을 수 있는 페이지군 계약을 제공해야 외부 AI 결과를 WordPress 템플릿과 블록으로 구현할 수 있다.

## Success

- 15개 요청 항목이 모두 독립된 기획과 제작 프롬프트를 가진다.
- 목록과 상세이 함께 필요한 항목은 양쪽 화면의 연결 관계가 명시된다.
- 각 페이지군에 목적, 대상, 전환, 화면 구성, 데이터 필드, 상태, 데스크톱·모바일 규칙이 있다.
- 현재 모두테마에서 재사용, 변형, 신규 제작할 자산이 구분된다.
- 프롬프트는 다른 문서를 보지 않아도 외부 AI가 실행할 수 있다.
- 허위 후기, 허위 수치, 허위 인증, 허위 가격을 만들지 않는 데이터 규칙이 있다.

## Constraints

- `docs/DESIGN.md`를 디자인 단일 기준으로 사용한다.
- 밝은 테마 하나, 단색 강조색 하나, 1200px 콘텐츠 폭, 390px 모바일을 기본으로 한다.
- 목록은 기본, 필터 적용, 검색 결과 없음, 로딩, 오류 상태를 포함한다.
- 상세는 정상, 데이터 일부 없음, 관련 콘텐츠 없음, CTA 불가 상태를 포함한다.
- 폼은 기본, 유효성 오류, 첨부 오류, 제출 중, 완료, 복구 상태를 포함한다.
- 상품과 예약은 가능, 잔여 소수, 품절·마감, 종료 상태를 포함한다.
- 3열 동일 아이콘 카드, 보라색 그라디언트, 과도한 둥근 모서리, 가짜 통계, 장식용 지도와 대시보드를 사용하지 않는다.
- 화면에 표시되는 문구에는 긴 대시 문자를 사용하지 않는다.
- 다단계 폼과 결제 화면은 마케팅 랜딩 규칙보다 명확한 입력·오류·복구 패턴을 우선한다.

## Out of scope

- 예약, 결제, 지도, 파일 저장, 회원 인증의 실제 백엔드 연동
- 의료·법률 결과, 제품 사양, 인증, 후기, 가격, 재고의 실제 값 생성
- WordPress 템플릿 구현과 라이브 배포
- 외부 AI 도구에서 실제 디자인 파일 생성
