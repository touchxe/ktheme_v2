# 모두 테마 Claude Design 업종별 통합 프롬프트 명세

Date: 2026-08-30  
Status: approved by user direction

## 목표

15개 업종을 한 번에 모두 생성하지 않고, 업종 하나를 선택할 때 그 업종에 필요한 전체 페이지 세트를 한 번의 Claude Design 요청으로 생성할 수 있게 한다.

## 결정

- 산출물은 업종별 독립 프롬프트 15개와 사용 인덱스로 구성한다.
- 이미 제공되는 디자인 규칙, 색상, 서체, 간격, 반응형 수치는 반복하지 않는다.
- 각 프롬프트는 업종 맥락, 핵심 사용자 흐름, 페이지별 목적·필수 내용·주요 행동, 필수 상태만 포함한다.
- 목록과 상세는 각각 독립 화면으로 생성한다.
- 공통 시스템 화면은 한 줄의 묶음으로 요청하고, 로그인은 회원 기능이 필요한 업종에만 강제한다.
- 출력 한계가 발생하면 페이지를 생략하지 않고 설명·장식 변형·중복 샘플 콘텐츠를 줄이도록 지시한다.

## 범위

포함: 홈, 소개, 업종 핵심 목록/상세, 전문가/사례/자료, 예약·상담·견적·구매 전환, 공통 정책·완료·오류 상태.  
제외: 디자인 토큰 재정의, 실제 브랜드의 규제·성과 수치 창작, 코드 구현, CMS 필드 설계, 결제·예약 백엔드 구현.

## 완료 기준

1. 15개 업종 각각에 독립 실행 가능한 프롬프트가 있다.
2. 기존 업종별 페이지 기획의 필수 페이지가 빠지지 않는다.
3. 각 페이지에 목적, 필수 내용, 주요 행동이 적혀 있다.
4. 목록·폼·예약·구매의 필수 상태가 정의되어 있다.
5. 프롬프트가 설명문 출력보다 실제 페이지 생성에 토큰을 우선하도록 지시한다.
