# KTheme 출시 점검표

출시 후보는 아래 항목을 모두 통과한 경우에만 배포합니다.

## 자동 검사

1. `pnpm test` — 기능이 예상대로 동작하는지 확인합니다.
2. `pnpm typecheck` — TypeScript 오류가 없는지 확인합니다.
3. `pnpm validate:extensions` — 새 패턴·프리셋·블록의 등록 정보가 규칙에 맞는지 확인합니다.
4. PHP lint와 WordPress 통합 테스트 — 실제 WordPress에서 테마와 플러그인이 켜지는지 확인합니다.
5. 브라우저·접근성 검사 — 메뉴, 폼, 모바일 화면, 키보드 사용성을 확인합니다.

## 사람이 확인할 항목

- 기본 테마, Engine, Church Preset을 각각 켜고 끄며 화면과 데이터가 안전한지 확인합니다.
- 새 설치에서 문서만 보고 로고·메뉴·패턴·스킨을 설정할 수 있는지 확인합니다.
- 모든 이미지·폰트·아이콘의 상업 사용 및 재배포 권한을 [ASSET_LICENSE_INVENTORY.md](ASSET_LICENSE_INVENTORY.md)에 기록합니다.
- 고객 이름, 실명, 연락처, 계좌, 실제 주소, 실제 서버 주소가 기본 테마와 Engine에 없는지 확인합니다.

## 데모 이미지의 마지막 확인 방법

현재 `assets/images/generated/`의 교회 데모 이미지는 출처 기록이 없어서 자동으로 출시를 멈춥니다. 아래 중 하나를 선택해 인벤토리에 기록해야 합니다.

| 선택 | 해야 할 일 | 결과 |
| --- | --- | --- |
| 직접 제작 | 제작자와 제작 날짜를 기록 | 상업 테마의 Church Preset 데모로 포함 가능 |
| 구매·구독 이미지 | 영수증/라이선스 URL과 재배포 허용 여부를 기록 | 약관 범위에서 포함 가능 |
| 재배포 허용 이미지 | 원본 URL과 라이선스 종류를 기록 | 표기 조건을 지켜 포함 가능 |
| 권리를 확인할 수 없음 | 이미지를 제거하거나 권리가 분명한 이미지로 교체 | 확인 전에는 ZIP에 넣지 않음 |

기록 뒤 `pnpm audit:release`를 실행합니다. 차단 항목이 0개여야 `pnpm package:release`가 실제 ZIP을 만듭니다.

## 배포 중단 기준

다음 중 하나라도 있으면 출시하지 않습니다.

- 사용자 동의 없는 콘텐츠 생성 또는 삭제
- 깨진 링크, 동작하지 않는 제출·결제 화면
- 라이선스가 확인되지 않은 배포 자산
- 필수 테스트 실패 또는 실제 WordPress 설치 실패
