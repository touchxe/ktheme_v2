# 교회/종교기관 사이트 분석

Date: 2026-08-30  
Status: research baseline  
Industry slug: `church-religious-organization`

## 조사 목적

교회·성당·사찰·교단/종단 기관을 하나의 화면에 억지로 섞지 않고, 공통 홈페이지 엔진 위에서 운영 방식이 다른 프리셋으로 분리하기 위한 조사다. 공개 데모의 첫 대상은 현재 ModuTheme 자산을 재사용할 수 있는 `church-local`로 정한다.

## 공통 메뉴 패턴

운영 주체가 달라도 다음 여섯 정보군은 반복된다.

1. 정체성: 기관 소개, 역사, 가치, 지도자/조직
2. 정기 모임: 예배·미사·법회·기도·수행의 날짜, 시간, 장소
3. 콘텐츠: 설교·강론·법문, 주보, 공지, 영상, 자료
4. 참여: 새가족/새신자, 공동체·단체, 교육, 봉사, 행사 신청
5. 지원: 헌금·교무금·보시·후원, 증명/영수증, 행정 문의
6. 방문: 주소, 교통, 주차, 접근성, 시설, 다국어

공통 정보군은 재사용하되 공개 메뉴명은 프리셋별 용어 사전을 사용한다. 예를 들어 개신교의 `예배/설교/새가족`, 천주교의 `미사/강론/예비신자`, 불교의 `법회/법문/신도`를 한 화면에서 병기하지 않는다.

## 전환 패턴

| 프리셋 | 1차 전환 | 2차 전환 | 반복 방문 동선 |
|---|---|---|---|
| `church-local` | 새가족 등록 | 예배시간, 오시는 길, 기도/문의 | 최근 설교, 주보, 행사 |
| `church-media` | 라이브/최근 예배 시청 | 캠퍼스 찾기, 대상별 예배, 새가족 등록 | 설교 시리즈, 행사, 교육 신청 |
| `catholic-parish` | 미사시간 확인 | 성사 안내, 사무실 문의, 단체/교육 신청 | 주보, 본당소식, 전례 일정 |
| `buddhist-temple` | 법회/기도 또는 체험 일정 확인 | 템플스테이 예약, 수행 신청, 오시는 길 | 법문, 사찰소식, 기도 안내 |
| `religious-organization` | 사업/자료 탐색 | 행사 등록, 기관 찾기, 후원/문의 | 공지, 자료실, 공식 입장 |

후원 자체를 모든 프리셋의 첫 전환으로 두지 않는다. 첫 방문자에게는 시간·장소·참여 방법이 우선이고, 후원은 기관의 목적과 사용처를 이해한 뒤 접근하도록 배치한다.

## 콘텐츠 블록

- 다음 예배·미사·법회 시간과 변경 공지
- 최근 설교·강론·법문 또는 공식 메시지
- 새 방문자 안내와 등록/문의 과정
- 연령·대상·관심사별 공동체/부서/신행 탐색
- 행사·교육 일정과 신청 상태
- 주보·공지·소식·자료 목록
- 지도, 주차, 대중교통, 접근성, 시설 사진
- 지도자/담당자 프로필과 담당 범위
- 헌금·보시·후원 목적, 방법, 영수증/문의 절차
- 개인정보·사진·상담·후원 관련 고지

## 시각 방향

- `church-local`: 지역 공동체와 환대를 보여 주는 따뜻한 편집형
- `church-media`: 라이브 상태와 영상을 먼저 보여 주는 미디어 포털형
- `catholic-parish`: 전례력·건축·기록의 품위를 살리는 절제형
- `buddhist-temple`: 문화재·계절·수행 공간을 담는 고요한 기록형
- `religious-organization`: 최신 사업·자료·일정 탐색성을 우선하는 기관 포털형

종교 상징을 장식 패턴처럼 과도하게 반복하지 않는다. 실제 공간, 활동, 사람, 기록을 중심으로 신뢰를 만든다. 교회형이라고 파란색, 성당형이라고 금색, 사찰형이라고 단청색만 바꾸는 방식은 프리셋 차이로 인정하지 않는다.

## 리스크 / 규제 / 주의사항

1. 기도·상담 요청에는 건강, 가족, 신앙 등 민감한 내용이 들어올 수 있으므로 공개 범위는 기본 비공개로 하고 최소 항목만 수집한다.
2. 아동·청소년, 상담자, 수혜자 사진은 게시 권한과 보호자 동의를 확인한다.
3. 헌금·보시·후원은 일반 상품 판매와 분리하고 사용 목적, 문의, 영수증 처리, 외부 결제 여부를 명확히 안내한다.
4. 예배·미사·법회 및 성사/기도 일정에는 적용 기간과 최종 갱신일을 표시한다.
5. 설교·찬양·공연·성보 문화재 이미지와 영상은 저작권 및 촬영 허용 범위를 확인한다.
6. 종교별 공식 용어와 절차는 해당 운영 주체가 승인해야 하며, 한 종교의 용어를 다른 프리셋에 자동 치환하지 않는다.
7. 위기 상담이나 긴급 상황은 온라인 폼이 즉시 대응 수단이 아님을 알리고 적절한 긴급 연락 안내를 제공한다.

## 데모 제작에 반영할 점

- 첫 데모는 현재 ModuTheme의 IA, `modutheme_sermon`, `modutheme_event`, `modutheme_album`을 활용해 `church-local`로 만든다.
- 홈페이지 상단에서 `다음 모임`, `처음 오셨나요`, `최근 메시지`를 한 화면 안에 확인할 수 있게 한다.
- 프리셋별 메뉴명, 1차 CTA, 콘텐츠 타입, 폼 필드, 고지 문구를 별도 데이터로 관리한다.
- `church-media`는 영상 장애 시 최근 콘텐츠를 보여 주는 대체 상태가 필요하다.
- `catholic-parish`는 미사/고해/성사 일정의 적용 기간과 본당 사무실 동선을 우선한다.
- `buddhist-temple`은 템플스테이 전체 예약 기능을 복제하지 않고 공식 외부 예약으로 연결할 수 있게 한다.
- `religious-organization`은 복잡한 조직도보다 최신 사업, 자료, 일정, 소속기관 찾기를 먼저 검증한다.

## 조사 단계 결론

`교회/종교기관`을 하나의 업종군으로 관리하는 것은 가능하지만, 하나의 범용 홈페이지를 제공하는 것은 적절하지 않다. 공통 컴포넌트와 데이터 구조를 공유하고, 공개 상품은 운영 언어와 전환 흐름이 다른 다섯 프리셋으로 분리해야 한다.
