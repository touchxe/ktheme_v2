# KTheme 사용자 가이드

## 1. 설치 순서

1. WordPress 관리자에서 `KTheme V2` 테마 ZIP을 업로드하고 활성화합니다.
2. `KTheme Engine` 플러그인을 설치하고 활성화합니다. 미디어·일정·자료·프로필 관리 메뉴가 추가됩니다.
3. 교회 사이트라면 `KTheme Church Preset`을 추가로 활성화합니다. 이 단계는 설교·예배 같은 표시 이름과 추천 구성을 적용할 뿐, 글이나 페이지를 자동으로 만들지 않습니다.
4. **외모 → 편집기**에서 로고, 메뉴, 템플릿 파트와 패턴을 편집합니다.

## 2. 새 페이지 만들기

1. 페이지를 만든 뒤 편집기에서 **패턴**을 엽니다.
2. `KTheme Pages`, `KTheme Sections`, `KTheme Queries` 중 필요한 묶음을 선택합니다.
3. 제목·문장·이미지·버튼 주소를 사이트 내용에 맞게 바꿉니다.

새 패턴은 기본 워드프레스 블록으로만 만들어져 있으므로, 별도 코드 없이 편집할 수 있습니다.

## 3. 콘텐츠 입력

| 관리 메뉴 | 쓰임 | 교회 프리셋 예시 |
| --- | --- | --- |
| Media | 영상·오디오·기록 | 설교 영상 |
| Events | 날짜와 장소가 있는 일정 | 예배·수련회 |
| Resources | 파일과 외부 링크 | 주보·자료실 |
| Profiles | 사람·팀 소개 | 목회자·교역자 |

프리셋을 꺼도 이미 입력한 콘텐츠는 사라지지 않습니다. 표시 이름만 기본 이름으로 돌아갑니다.

## 4. 스킨과 디자인

기본 스킨은 `Foundation`입니다. **외모 → 편집기 → 스타일**에서 선택할 수 있습니다. 스킨을 바꾸면 색·글꼴 같은 디자인 값만 바뀌고, 페이지 내용이나 메뉴는 바뀌지 않습니다.

## 5. 외부 기능 연결

문의·신청 폼, 결제, 지도 기능은 검증한 외부 플러그인으로 연결합니다. KTheme의 통합 패턴은 연결 위치와 안내 문구를 제공하지만, 실제 전송·결제 기능을 흉내 내지 않습니다.

## 6. 업데이트와 백업

업데이트 전에는 데이터베이스와 업로드 파일을 백업합니다. 테마를 바꾸거나 KTheme Engine을 잠시 끄더라도 엔진이 만든 콘텐츠는 삭제되지 않습니다. 플러그인 제거도 콘텐츠를 자동 삭제하지 않습니다.

## 7. 문제 해결

- 콘텐츠 메뉴가 보이지 않으면 KTheme Engine이 활성화되어 있는지 확인합니다.
- 교회용 이름이 보이지 않으면 KTheme Church Preset을 활성화합니다.
- 화면이 비어 있으면 해당 패턴의 텍스트·이미지·링크를 먼저 입력하고, 콘텐츠 목록 패턴에는 해당 콘텐츠를 하나 이상 등록합니다.
