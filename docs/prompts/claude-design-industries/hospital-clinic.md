# 병원/의원 전체 페이지 생성 프롬프트

```text
모두 테마의 병원/의원 웹사이트 전체 페이지 세트를 하나의 연결된 프로젝트로 생성하라.

[입력값]
- 브랜드명: [병원명]
- 업체 유형: [의원/전문클리닉/검진센터/치과/한의원]
- 적용 프리셋: [medical-specialty/medical-local-clinic/medical-booking/medical-facility]
- 핵심 진료: [대표 진료 3~6개]
- 지점·의료진·진료시간 자료: [제공 자료 또는 없음]

[실행 원칙]
- 이미 제공된 모두 테마 디자인 규칙을 그대로 적용하고 새 디자인 규칙을 만들거나 설명하지 마라.
- 아래 모든 페이지를 같은 헤더·푸터·내비게이션과 재사용 컴포넌트로 연결해 실제 페이지 프레임으로 생성하라.
- 설명 보고서를 쓰지 말고 생성 결과에 토큰을 사용하라. 한계가 있으면 장식 변형과 샘플 문구를 줄이되 페이지는 생략하지 마라.
- 사실 자료가 없으면 짧은 한국어 예시를 사용하되 의료진 자격, 치료 효과, 수치, 인증을 사실처럼 창작하지 말고 ‘예시’ 또는 확인 필요 항목으로 표시하라.
- 핵심 흐름은 증상·목적 탐색 → 진료/의료진 확인 → 날짜·시간 선택 → 예약 완료 → 길찾기다.

[생성할 페이지]
1. 홈 — 목적: 적합한 진료와 예약으로 빠르게 연결. 내용: 운영/진료시간, 증상·목적별 탐색, 대표 진료, 의료진, 시설·장비, 위치, 의료 고지. 주요 행동: 진료 예약, 전화·상담.
2. 병원 소개 — 목적: 진료 철학과 운영 신뢰 설명. 내용: 원장 메시지, 진료 원칙, 연혁, 협력기관, 위치. 주요 행동: 의료진 보기, 오시는 길.
3. 진료과목 목록 — 목적: 목적·증상별 진료 탐색. 내용: 분류/검색, 대상, 대표 증상, 담당 의료진, 예약 가능 여부. 주요 행동: 상세 보기.
4. 진료과목 상세 — 목적: 대상·범위·과정·주의사항 이해. 내용: 대상, 진료 범위, 검사/치료 흐름, 준비사항, 담당자, FAQ, 의료 고지. 주요 행동: 이 진료 예약.
5. 치료·검진 프로그램 목록 — 목적: 프로그램 비교. 내용: 분류, 포함 항목, 기간, 가격 또는 문의, 담당자, 상태, 고지. 주요 행동: 상세·상담.
6. 프로그램 상세 — 목적: 프로그램 선택 정보 제공. 내용: 목표, 대상, 포함/제외, 일정, 진행 단계, 담당 의료진, 비용 안내, 주의사항. 주요 행동: 예약·문의.
7. 의료진 목록 — 목적: 전문분야에 맞는 담당자 선택. 내용: 사진, 이름, 직위, 진료분야, 주요 경력, 진료 일정. 주요 행동: 의료진 상세.
8. 의료진 상세 — 목적: 개인 전문성과 예약 연결. 내용: 약력, 자격, 학회/논문, 전문분야, 진료시간, 관련 진료·프로그램. 주요 행동: 의료진 지정 예약.
9. 시설·장비 — 목적: 안전·접근성·진료환경 확인. 내용: 시설 갤러리, 장비명과 용도, 편의시설, 접근성, 위치. 주요 행동: 상담·길찾기.
10. 예약·상담 — 목적: 예약 접수 완료. 내용: 진료분야 → 의료진 → 날짜 → 가능 시간 → 환자 기본정보 → 동의 → 확인의 단계형 흐름. 주요 행동: 예약 확정.
11. 공지·FAQ — 목적: 방문 전 운영 변경과 반복 질문 해결. 내용: 휴진/시간 변경 공지 목록·상세, 준비사항, 주차, 예약 변경·취소, FAQ. 주요 행동: 예약·전화.
12. 오시는 길 — 목적: 방문 실패 방지. 내용: 지도, 주소, 대중교통, 주차, 층/출입구, 진료시간, 연락처. 주요 행동: 길찾기·전화.

[필수 상태와 시스템 화면]
- 목록: 기본, 필터 적용, 검색 결과 없음.
- 예약: 날짜/시간 가능, 마감, 휴진, 선택 전, 검증 오류, 전송 중, 완료.
- 공통: 검색 결과, 404, 개인정보처리방침, 이용약관·예약 취소 안내, 폼 완료, 빈 상태·연동 오류.
- 모든 페이지에서 의료광고·개인정보·응급상황 한계를 필요한 위치에 명확히 표시하라.
```
