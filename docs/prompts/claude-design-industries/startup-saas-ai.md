# 스타트업/SaaS/문제특화 AI 전체 페이지 생성 프롬프트

```text
모두 테마의 스타트업/SaaS/문제특화 AI 제품 웹사이트 전체 페이지 세트를 하나의 연결된 프로젝트로 생성하라.

[입력값]
- 제품·회사명: [이름]
- 업체 유형: [B2B SaaS/업무 플랫폼/AI 솔루션/데이터/개발자 도구]
- 적용 프리셋: [saas-product/saas-enterprise/saas-problem-specific-ai/saas-developer-tool]
- 핵심 사용자·문제: [역할과 문제]
- 기능·연동·가격·사례 자료: [제공 자료 또는 없음]

[실행 원칙]
- 제공된 모두 테마 디자인 규칙을 적용하고 새로운 디자인 규칙을 설명하지 마라.
- 아래 페이지를 하나의 제품 웹사이트 IA와 공통 기능·사례·가격 컴포넌트로 연결한 실제 페이지 프레임으로 모두 생성하라.
- 설명 보고서를 생략하고 화면 제작에 토큰을 사용한다. 한계가 있으면 장식과 반복 카피를 줄이고 페이지는 유지한다.
- 고객사, 성과 수치, 보안 인증, AI 정확도, 가격, 연동 상태는 자료 없이는 창작하지 않고 예시/확인 필요로 표시한다.
- 핵심 흐름은 문제 이해 → 기능·사용 흐름 확인 → 사례·요금·보안 검토 → 데모 신청이다.

[생성할 페이지]
1. 홈 — 핵심 문제, 제품 가치, 대표 기능, 사용 흐름, 연동, 고객/사례, 요금 예고, 보안, 데모 CTA. 주요 행동: 제품 보기·데모 신청.
2. 제품·기능 목록 — 역할·문제·기능군별 탐색, 기능 관계, 통합 설명. 주요 행동: 기능 상세.
3. 기능 상세 — 해결 문제, 실제 화면 영역, 입력/출력, 사용 단계, 권한, 연동, 보안, 관련 사례. 주요 행동: 데모.
4. 사용 흐름 — 시작, 데이터/연동 설정, 협업, 자동화/AI 처리, 결과, 관리자 흐름. 주요 행동: 기능·데모.
5. 연동·API 목록 — 연동 범주, 상태, 인증 방식, API/SDK 자료, 요청 기능. 주요 행동: 연동 상세·문서.
6. 연동·API 상세 — 연결 가치, 요구 조건, 설정 단계, 데이터 범위, 제한, 문서 링크. 주요 행동: 기술 문의.
7. 고객사·사례 목록 — 업종·규모·사용기능 필터, 고객 맥락, 검증 가능한 성과. 주요 행동: 사례 상세.
8. 사례 상세 — 배경, 문제, 선택 이유, 도입 과정, 변화, 측정 수치와 출처, 인용, 관련 기능. 주요 행동: 데모.
9. 요금 — 대상, 기능, 사용량, 가격/문의, 추천 플랜, 비교표, 추가비용, FAQ. 주요 행동: 플랜 선택·영업 문의.
10. 자료실 목록 — 보고서, 가이드, 웨비나, 개발문서의 유형·주제 필터. 주요 행동: 자료 상세.
11. 자료 상세 — 요약, 목차, 대상, 미리보기, 작성/개정일, 다운로드 폼 여부. 주요 행동: 다운로드.
12. 보안·신뢰 — 데이터 흐름, 권한, 저장/삭제, 운영통제, 인증 자리, FAQ와 책임 범위. 주요 행동: 보안 자료·문의.
13. 데모 신청 — 회사, 역할, 문제, 규모, 현재 도구, 필요한 연동, 희망 일정, 연락처, 동의. 주요 행동: 데모 접수.
14. 문의 — 일반/기술/파트너 유형, 내용, 회사, 회신 방식, 동의. 주요 행동: 문의 접수.
15. FAQ — 가격, 보안, 데이터, AI 한계, 계약, 도입, 지원, 해지. 주요 행동: 데모·문의.

[필수 상태와 시스템 화면]
- 요금·자료·연동: 기본, 필터, 결과 없음, 준비 중/지원됨/지원 종료.
- 폼: 조건부 문항, 검증 오류, 전송 중, 완료, 실패.
- 공통: 검색 결과, 404, 개인정보처리방침, 서비스 이용약관, 폼 완료, 빈 상태·연동 오류. 실제 제품 계정이 연결되면 로그인 진입만 포함한다.
```
