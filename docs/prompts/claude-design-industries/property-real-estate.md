# 부동산/분양 전체 페이지 생성 프롬프트

```text
모두 테마의 부동산/분양 웹사이트 전체 페이지 세트를 하나의 연결된 프로젝트로 생성하라.

[입력값]
- 브랜드·사업명: [사업명 또는 중개 브랜드]
- 업체 유형: [분양대행/시행사/모델하우스/중개법인/상업시설]
- 적용 프리셋: [property-sales/residential-complex/commercial-property/local-brokerage]
- 위치·규모·주요 타입: [제공 정보]
- 일정·도면·입지 자료: [제공 자료 또는 없음]

[실행 원칙]
- 제공된 모두 테마 디자인 규칙을 적용하고 디자인 규칙 자체는 반복하지 마라.
- 아래 모든 페이지를 같은 프로젝트의 공통 내비게이션·타입·지도 컴포넌트로 연결한 실제 페이지 프레임으로 생성하라.
- 설명문보다 페이지 제작에 토큰을 우선한다. 한계가 있으면 장식과 중복 예시를 줄이고 페이지는 유지한다.
- 분양가, 개발계획, 거리, 시간, 수익, 공급 일정은 제공된 출처가 없으면 사실처럼 창작하지 말고 예시/확인 필요로 표시한다.
- 핵심 흐름은 사업 가치 확인 → 입지·타입 비교 → 평면 상세 → 일정·방문 확인 → 관심고객 등록이다.

[생성할 페이지]
1. 홈 — 사업명, 위치, 핵심 일정, 대표 타입, 프리미엄, 입지 지도, 관심고객 등록. 주요 행동: 타입 보기·방문/등록.
2. 사업개요 — 위치, 규모, 세대/호실, 시행·시공, 일정, 공식 고지와 유의사항. 주요 행동: 입지·타입 확인.
3. 입지환경 — 교통, 학교, 상권, 공원, 거리/시간, 개발계획과 출처, 지도 필터. 주요 행동: 주변 보기·길찾기.
4. 타입·평면 목록 — 타입 카드, 공급/전용면적, 방·공간, 방향, 대표 도면, 비교 선택. 주요 행동: 타입 상세·비교.
5. 타입 비교 — 선택 타입 2~4개의 면적, 공간, 방향, 옵션, 특징을 같은 기준으로 비교. 주요 행동: 타입 상세·관심 등록.
6. 타입 상세 — 확대/축소 가능한 평면, 면적표, 공간별 설명, 옵션, 이미지 갤러리, 유의사항. 주요 행동: 관심 타입 등록.
7. 프리미엄 — 입지, 설계, 커뮤니티, 브랜드의 구매 근거와 출처·조건. 주요 행동: 사업개요·등록.
8. 단지·시설 — 단지 배치도, 커뮤니티 시설, 동선, 접근성, 이미지와 위치 연결. 주요 행동: 시설 보기·방문.
9. 분양일정 — 공급/청약/계약/입주 일정의 달력·타임라인, 현재/예정/종료 상태, 변경 고지. 주요 행동: 알림·등록.
10. 관심고객 등록 — 관심 타입, 거주지역, 연락처, 방문 희망일, 상담 방식, 개인정보·마케팅 동의 분리. 주요 행동: 등록 완료.
11. 공지·FAQ — 분양 공지 목록·상세, 자격/일정, 방문, 서류, 유의사항, FAQ. 주요 행동: 등록·문의.
12. 오시는 길 — 모델하우스/현장 지도, 주차, 대중교통, 운영시간, 전화. 주요 행동: 길찾기·전화.

[필수 상태와 시스템 화면]
- 타입·지도: 미선택, 선택/비교, 결과 없음, 확대 도면, 데이터 준비 중.
- 일정·등록: 예정, 진행, 마감, 변경; 폼 기본, 오류, 전송 중, 완료.
- 공통: 검색 결과, 404, 개인정보처리방침, 이용약관·부동산 표시/광고 고지, 폼 완료, 빈 상태·오류.
```
