# 교회/종교기관 전체 페이지 생성 프롬프트

```text
모두 테마의 교회/종교기관 웹사이트 전체 페이지 세트를 하나의 연결된 프로젝트로 생성하라.

[입력값]
- 공동체·기관명: [이름]
- 업체 유형: [지역/다지점 교회/천주교 본당/불교 사찰/교단·종단/선교·복지·교육기관]
- 적용 프리셋: [church-local/church-media/catholic-parish/buddhist-temple/religious-organization]
- 전통별 용어: [예배·말씀/미사·강론/법회·법문 등]
- 모임·지도자·미디어·행사 자료: [제공 자료 또는 없음]

[실행 원칙]
- 제공된 모두 테마 디자인 규칙을 그대로 적용하고 새 디자인 규칙을 설명하지 마라.
- 아래 모든 페이지를 공통 내비게이션과 모임·미디어·행사·공동체 컴포넌트로 연결한 실제 페이지 프레임으로 생성하라.
- 설명문보다 페이지 제작에 토큰을 우선한다. 한계가 있으면 장식 변형과 중복 예시를 줄이고 페이지는 유지한다.
- 교단/종단, 지도자, 역사, 모임시간, 후원 사용처를 자료 없이는 사실처럼 창작하지 않는다. 입력한 전통의 용어를 일관되게 사용한다.
- 핵심 흐름은 정기 모임 확인 → 첫 방문 안내 → 행사·공동체 참여 → 메시지·자료 이용 → 후원·문의다.
- 메뉴와 주소는 제공된 사이트 IA 기준을 우선하며 영문 소문자 kebab-case를 사용한다. 교회형 기본 주소는 /about/, /worship/, /media/, /community/, /training/, /mission/, /contact/ 체계를 따른다.

[생성할 페이지]
1. 홈 — 다음 예배/미사/법회, 최신 메시지, 새 방문자, 행사, 공동체 소식, 위치, 후원. 주요 행동: 모임 확인·첫 방문.
2. 기관·공동체 소개 — 비전, 역사, 지도자, 조직, 시설, 소속기관. 주요 행동: 모임·오시는 길.
3. 지도자·조직 — 지도자/담당자 목록, 역할, 약력, 담당 공동체. 주요 행동: 상세·문의.
4. 정기 모임 안내 — 유형, 요일/시간, 장소, 언어/대상, 변경 공지, 온라인 참여. 주요 행동: 길찾기·라이브.
5. 말씀·강론·법문 목록 — 날짜, 연사, 본문/주제, 시리즈/절기, 영상/음성 필터. 주요 행동: 메시지 상세.
6. 메시지 상세 — 플레이어, 제목, 연사, 날짜, 본문/주제, 대본/요약, 다운로드, 관련 메시지. 주요 행동: 재생·공유.
7. 일정·행사 목록 — 달력/목록, 대상, 장소, 신청/마감, 변경 상태. 주요 행동: 행사 상세.
8. 행사 상세 — 일정, 장소, 대상, 준비물, 정원, 신청, 담당자, 관련 자료. 주요 행동: 행사 신청.
9. 새가족·새신자 안내 — 첫 방문 동선, 예절/준비, 가족·접근성 안내, 등록 단계, 담당자, FAQ. 주요 행동: 첫 방문/등록 신청.
10. 교육·수행 프로그램 목록 — 대상, 기간, 일정, 담당자, 신청 상태. 주요 행동: 프로그램 상세.
11. 교육·수행 프로그램 상세 — 목표, 대상, 커리큘럼, 일정, 준비, 담당자, 신청. 주요 행동: 신청.
12. 부서·공동체 목록 — 연령·관심사별 모임, 시간/장소, 담당자, 활동. 주요 행동: 공동체 상세.
13. 부서·공동체 상세 — 소개, 대상, 모임, 활동, 담당자, 사진, 문의/참여. 주요 행동: 참여 문의.
14. 봉사·사역 목록 — 역할, 대상/조건, 시간, 교육, 담당자, 모집 상태. 주요 행동: 봉사 상세.
15. 봉사·사역 상세 — 목적, 역할, 일정, 준비/교육, 담당자, 신청. 주요 행동: 참여 신청.
16. 소식·주보 목록 — 공지, 주보, 기관 소식의 유형·기간 필터, 중요 표시, 첨부. 주요 행동: 상세·다운로드.
17. 소식·주보 상세 — 본문, 게시일, 담당부서, 첨부, 관련 소식. 주요 행동: 다운로드.
18. 미디어·자료실 — 영상/사진/문서 유형 필터, 앨범, 자료 버전, 다운로드. 주요 행동: 미디어·자료 상세.
19. 후원·헌금·보시 안내 — 지원 유형, 사용 목적, 참여 방법, 영수증, 문의, 투명성/개인정보 고지. 주요 행동: 후원 방법 확인.
20. 시설·오시는 길 — 지도, 교통, 주차, 시설, 접근성, 캠퍼스/지점. 주요 행동: 길찾기.
21. 문의·신청 — 일반, 기도, 상담, 행정 요청 유형, 공개범위, 내용, 회신 방식, 동의, 긴급 안내. 주요 행동: 접수.

[필수 상태와 시스템 화면]
- 미디어·행사·자료: 필터, 결과 없음, 라이브 예정/진행/종료, 신청 가능/마감, 재생/파일 오류.
- 문의·신청: 민감 요청의 공개범위, 검증 오류, 전송 중, 완료, 긴급 도움 안내.
- 공통: 검색 결과, 404, 개인정보처리방침, 이용약관·후원 안내, 로그인·회원가입(회원 기능 사용 시), 폼 완료, 빈 상태·오류.
- 선교 관련 정보는 /mission/에 통합하고 별도의 ‘선교소식’ 메뉴를 만들지 말며, ‘교단소식’은 미디어 하위에 유지하라.
```
