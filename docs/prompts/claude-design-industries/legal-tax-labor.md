# 법률/세무/노무 전체 페이지 생성 프롬프트

```text
모두 테마의 법률/세무/노무 전문사무소 웹사이트 전체 페이지 세트를 하나의 연결된 프로젝트로 생성하라.

[입력값]
- 브랜드명: [사무소명]
- 업체 유형: [법무법인/변호사/세무사/노무사/행정사 사무소]
- 적용 프리셋: [professional-practice/professional-team/professional-case/professional-local-office]
- 핵심 전문분야: [분야 3~6개]
- 구성원·사례·지점 자료: [제공 자료 또는 없음]

[실행 원칙]
- 제공된 모두 테마 디자인 규칙을 적용하고 디자인 규칙 자체는 재작성하지 마라.
- 아래 페이지를 공통 내비게이션과 컴포넌트로 연결해 실제 페이지 프레임으로 모두 생성하라.
- 설명문은 최소화하고 페이지 생성에 토큰을 우선 사용한다. 한계가 있으면 장식 변형을 줄이고 페이지는 유지한다.
- 확인되지 않은 자격, 승소율, 절세액, 고객명, 사건 결과는 창작하지 않는다. 사례는 익명 예시와 결과 비보장 고지를 사용한다.
- 핵심 흐름은 문제 선택 → 전문분야·구성원 확인 → 유사 사례 검토 → 상담 신청이다.

[생성할 페이지]
1. 홈 — 문제별 진입, 대표 전문분야, 구성원, 사례, 진행절차, 자료, 위치, 면책. 주요 행동: 상담 신청.
2. 사무소 소개 — 철학, 연혁, 업무 원칙, 자격/등록 확인 영역, 지역·지점. 주요 행동: 구성원 보기.
3. 전문분야 목록 — 문제/업무 분류, 대상, 주요 쟁점, 준비자료, 담당자. 주요 행동: 분야 상세.
4. 전문분야 상세 — 가능한 업무와 제외 범위, 절차, 예상 기간, 필요서류, 비용 안내 방식, 관련 담당자·사례, 면책. 주요 행동: 이 분야 상담.
5. 구성원 목록 — 자격, 전문분야, 경력, 언어, 소속 지점, 상담 가능 상태. 주요 행동: 프로필 보기.
6. 구성원 상세 — 약력, 검증 가능한 자격, 주요업무, 기고/강의, 관련 사례·자료, 상담 연결. 주요 행동: 담당자 지정 상담.
7. 성공사례 목록 — 분야·상황 필터, 익명 문제 요약, 대응 방향, 결과 맥락, 면책. 주요 행동: 사례 상세.
8. 사례 상세 — 배경, 쟁점, 전략, 진행 과정, 결과, 적용 제한, 관련 서비스·구성원. 주요 행동: 유사 문제 상담.
9. 자료실 목록 — 칼럼, 체크리스트, 일정, 서식의 유형·주제 필터와 최신성/버전. 주요 행동: 자료 상세·다운로드.
10. 자료 상세 — 요약, 본문/미리보기, 작성자, 검토일, 관련 법령·서비스, 파일. 주요 행동: 다운로드·상담.
11. 상담 신청 — 문의분야, 상황 요약, 상대방/기한 등 충돌 확인용 최소 정보, 희망 일정, 연락처, 파일 첨부, 개인정보 동의, 긴급·면책 안내. 주요 행동: 접수.
12. 오시는 길 — 지점, 주소, 주차, 방문시간, 담당 연락처, 온라인 상담 안내. 주요 행동: 길찾기·전화.

[필수 상태와 시스템 화면]
- 목록: 기본, 필터 적용, 결과 없음.
- 파일 첨부 폼: 기본, 파일 형식/용량 오류, 필수값 오류, 전송 중, 접수 완료.
- 공통: 검색 결과, 404, 개인정보처리방침, 이용약관·상담 면책, 폼 완료, 빈 상태·오류.
- 민감정보는 최소 수집하고 공개 사례와 상담 폼 모두 비밀유지·결과 비보장 범위를 명시하라.
```
