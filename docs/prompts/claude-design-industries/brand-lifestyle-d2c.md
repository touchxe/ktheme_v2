# 브랜드/라이프스타일 D2C 전체 페이지 생성 프롬프트

```text
모두 테마의 브랜드/라이프스타일 D2C 커머스 웹사이트 전체 페이지 세트를 하나의 연결된 프로젝트로 생성하라.

[입력값]
- 브랜드명: [브랜드명]
- 업체 유형: [뷰티/로컬식품/리빙/패션잡화/친환경/반려동물/공예/구독]
- 적용 프리셋: [brand-beauty/brand-food/brand-living/brand-subscription]
- 핵심 상품군·구매 목적: [3~8개]
- 상품·성분·배송·프로모션 자료: [제공 자료 또는 없음]

[실행 원칙]
- 제공된 모두 테마 디자인 규칙을 적용하고 디자인 규칙 자체는 다시 설명하지 마라.
- 아래 페이지를 하나의 쇼핑 경험과 공통 상품·장바구니·계정 컴포넌트로 연결한 실제 페이지 프레임으로 모두 생성하라.
- 보고서보다 화면 제작에 토큰을 우선한다. 한계가 있으면 장식 변형과 반복 상품 샘플을 줄이고 페이지는 유지한다.
- 가격, 재고, 성분/원산지, 인증, 효능, 리뷰, 배송일은 자료 없이는 사실처럼 창작하지 말고 예시/확인 필요로 표시한다.
- 핵심 흐름은 목적별 상품 탐색 → 상세·근거·리뷰 확인 → 장바구니 → 결제 → 주문/구독 관리다.

[생성할 페이지]
1. 홈 — 캠페인, 브랜드 이유, 상품군, 대표상품, 목적별 추천, 소재/공정, 리뷰, 프로모션. 주요 행동: 상품 보기·구매.
2. 브랜드 이야기 — 시작, 미션, 사람, 지역, 지속가능성, 검증 가능한 근거. 주요 행동: 상품 보기.
3. 상품 목록 — 카테고리·목적·가격·속성 필터, 정렬, 가격, 재고, 할인/구독 상태. 주요 행동: 상품 상세·빠른 담기.
4. 상품 상세 — 미디어, 옵션, 가격, 재고, 배송, 성분/소재, 사용법, 주의, 리뷰, 관련상품. 주요 행동: 장바구니·바로 구매·구독.
5. 상품 비교 — 선택 상품 2~4개의 용도, 구성, 소재/성분, 용량, 가격, 단위가격, 배송/구독 비교. 주요 행동: 상품 선택.
6. 목적별 추천 — 짧은 질문/필터, 선택 요약, 추천 근거, 추천 상품 비교, 다시 시작. 주요 행동: 추천 상품 보기·담기.
7. 소재·성분·제조 — 원료/소재, 원산지, 성분, 공정, 인증 문서, 추적·검증 정보. 주요 행동: 관련 상품 보기.
8. 사용 가이드 — 단계, 빈도/용량, 팁, 주의, 보관, 관련 상품. 주요 행동: 상품 보기.
9. 리뷰·UGC 목록 — 상품·평점·사용맥락 필터, 구매 인증, 사진/영상, 광고/승인 표시. 주요 행동: 리뷰 상세·상품 보기.
10. 리뷰·콘텐츠 상세 — 이용 맥락, 미디어, 개인차/광고 고지, 관련 상품·가이드. 주요 행동: 상품 구매.
11. 프로모션 — 기간, 대상, 쿠폰, 세트, 구독 혜택, 조건, 진행/종료 상태. 주요 행동: 혜택 적용 상품 보기.
12. FAQ·고객지원 — 배송, 교환/환불, 성분/주의, 구독, 주문 변경, 문의. 주요 행동: 문의.
13. 장바구니 — 옵션/수량, 삭제/저장, 쿠폰, 배송 예상, 세트 추천, 합계, 빈 상태. 주요 행동: 결제.
14. 결제 — 주문자, 배송지, 배송 방법, 쿠폰/포인트, 결제, 약관, 주문 요약. 주요 행동: 주문 완료.
15. 주문 완료 — 주문번호, 상품/금액, 배송 요약, 다음 행동, 계정 연결. 주요 행동: 주문 조회.
16. 로그인·회원가입 — 로그인, 가입, 비회원 주문조회, 인증, 오류. 주요 행동: 계정 진입.
17. 내 계정 — 주문/배송, 취소·교환, 주소, 리뷰, 저장 상품, 구독 관리. 주요 행동: 주문·구독 관리.
18. 구독 관리 — 다음 결제/배송, 구성, 주기, 주소, 건너뛰기, 변경/해지 조건. 주요 행동: 변경 저장.

[필수 상태와 시스템 화면]
- 상품: 판매중, 재고 임박, 품절, 판매 종료, 옵션 미선택, 할인 종료.
- 장바구니·결제: 빈 장바구니, 쿠폰 오류, 재고 변경, 결제 중, 결제 실패, 주문 완료.
- 계정·구독: 주문 없음, 배송 단계, 해지 확인, 인증 오류.
- 공통: 검색 결과, 404, 개인정보처리방침, 이용약관·배송/교환/환불·구독정책, 폼 완료, 빈 상태·오류.
```
