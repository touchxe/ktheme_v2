# 지역관광/체험/문화 전체 페이지 생성 프롬프트

```text
모두 테마의 지역관광/체험/문화 웹사이트 전체 페이지 세트를 하나의 연결된 프로젝트로 생성하라.

[입력값]
- 브랜드·장소명: [이름]
- 업체 유형: [체험농장/공방/수목원/로컬투어/관광협회·문화재단/축제/숙박]
- 적용 프리셋: [local-experience/local-destination/local-event/local-stay]
- 대표 지역·프로그램: [지역과 3~8개 프로그램]
- 일정·정원·지도·운영자 자료: [제공 자료 또는 없음]

[실행 원칙]
- 제공된 모두 테마 디자인 규칙을 적용하고 디자인 규칙을 새로 설명하지 마라.
- 아래 모든 페이지를 공통 내비게이션과 프로그램·일정·지도 컴포넌트로 연결한 실제 페이지 프레임으로 생성하라.
- 보고서 대신 페이지 제작에 토큰을 사용한다. 한계가 있으면 장식 변형과 중복 예시를 줄이고 페이지는 유지한다.
- 운영시간, 가격, 정원, 거리, 기상, 안전, 접근성, 제휴 혜택은 자료 없이는 사실처럼 창작하지 말고 예시/확인 필요로 표시한다.
- 핵심 흐름은 날짜·인원 확인 → 프로그램/코스 선택 → 상세·준비사항 확인 → 예약이며, 단체는 별도 견적 문의로 연결한다.

[생성할 페이지]
1. 홈 — 오늘/선택일 가능한 경험, 날짜·인원 진입, 추천 프로그램, 계절 코스, 주변 지도, 후기, 공지. 주요 행동: 프로그램 찾기·예약.
2. 브랜드·운영자 이야기 — 시작, 지역과 사람, 운영 철학, 지속가능성, 작업/운영 과정, 사진. 주요 행동: 프로그램 보기.
3. 프로그램·상품 목록 — 체험/투어/행사/숙박 유형, 날짜, 대상, 소요시간, 가격, 가능 상태 필터. 주요 행동: 프로그램 상세.
4. 프로그램 상세 — 일정, 대상, 포함/불포함, 준비물, 안전·취소, 위치, 가격/옵션, 후기, 남은 정원. 주요 행동: 이 프로그램 예약.
5. 일정·예약 — 프로그램 → 날짜 → 시간 → 인원/정원 → 옵션 → 예약자 정보 → 동의 → 확인의 단계형 흐름. 주요 행동: 예약 확정.
6. 추천 코스 목록 — 체류시간, 동반유형, 이동수단, 계절별 코스 탐색. 주요 행동: 코스 상세.
7. 추천 코스 상세 — 순서형 방문지, 시간, 거리, 교통, 지도 경로, 연결 프로그램, 식사/휴식, 유의사항. 주요 행동: 프로그램 예약·경로 보기.
8. 주변 관광 지도 — 카테고리·거리 필터, 지도/목록, 운영시간, 접근성, 제휴 혜택. 주요 행동: 장소 상세·길찾기.
9. 주변 장소 상세 — 사진, 소개, 위치, 시간, 이동 방법, 관련 코스·프로그램. 주요 행동: 길찾기.
10. 갤러리 — 공간·계절·경험 유형 필터, 사진/영상, 캡션, 관련 프로그램. 주요 행동: 프로그램 보기.
11. 후기 목록 — 프로그램·계절·동반유형 필터, 사진, 이용 맥락, 승인/고지. 주요 행동: 후기 상세·예약.
12. 후기 상세 — 방문 배경, 일정, 경험, 사진, 관련 프로그램, 개인 경험 고지. 주요 행동: 프로그램 예약.
13. 단체·제휴 문의 — 단체유형, 인원, 일정, 목적, 예산, 식사/교통, 접근성, 제휴유형, 파일, 연락처·동의. 주요 행동: 문의 접수.
14. 공지·FAQ — 기상/휴무/운영 변경 공지 목록·상세, 환불, 복장, 연령, 반려동물, 접근성 FAQ. 주요 행동: 예약·문의.
15. 오시는 길 — 지도, 교통, 주차, 입구, 셔틀/주변 연결, 연락처. 주요 행동: 길찾기.

[필수 상태와 시스템 화면]
- 프로그램·예약: 가능, 잔여 임박, 마감, 운영 종료, 기상 취소, 대기, 인원 초과.
- 지도·목록: 기본, 필터, 결과 없음, 위치 권한 거부, 지도 오류.
- 폼: 검증 오류, 결제/전송 중, 완료, 실패·재시도.
- 공통: 검색 결과, 404, 개인정보처리방침, 이용약관·취소/환불정책, 폼 완료, 빈 상태·오류.
```
