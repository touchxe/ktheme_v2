# 포트폴리오/에이전시 전체 페이지 생성 프롬프트

```text
모두 테마의 포트폴리오/에이전시 웹사이트 전체 페이지 세트를 하나의 연결된 프로젝트로 생성하라.

[입력값]
- 브랜드명: [에이전시/스튜디오명]
- 업체 유형: [디자인/개발/영상/마케팅/브랜딩/콘텐츠]
- 적용 프리셋: [agency-cases/agency-services/agency-editorial/studio-profile]
- 핵심 역량·선호 프로젝트: [3~6개]
- 프로젝트·팀·성과 자료: [제공 자료 또는 없음]

[실행 원칙]
- 제공된 모두 테마 디자인 규칙을 그대로 적용하고 별도 디자인 규칙을 작성하지 마라.
- 아래 페이지를 공통 내비게이션과 프로젝트·서비스 컴포넌트로 연결한 실제 페이지 프레임으로 모두 생성하라.
- 설명문보다 페이지 결과에 토큰을 사용한다. 한계가 있으면 장식 변형과 긴 샘플 카피를 줄이고 페이지는 유지한다.
- 고객명, 수상, 성과 수치, 프로젝트 크레딧은 자료 없이는 창작하지 않고 명확한 예시로 처리한다.
- 핵심 흐름은 대표 프로젝트 탐색 → 서비스·프로세스·팀 확인 → 프로젝트 브리프와 파일을 포함한 문의다.

[생성할 페이지]
1. 홈 — 대표 프로젝트, 핵심 서비스, 검증 가능한 성과, 프로세스, 팀, 인사이트, 문의 CTA. 주요 행동: 프로젝트 보기·문의.
2. 소개 — 관점, 철학, 역사, 팀 문화, 수상/파트너 자리, 일하는 방식. 주요 행동: 서비스·팀 보기.
3. 서비스 목록 — 분야, 적합 고객, 산출물, 기간, 협업 방식, 가격/문의. 주요 행동: 서비스 상세.
4. 서비스 상세 — 문제, 범위, 산출물, 단계, 일정, 협업 조건, 관련 프로젝트·팀. 주요 행동: 프로젝트 문의.
5. 프로젝트 목록 — 작업유형·산업·서비스 필터, 대표 이미지, 클라이언트 맥락, 역할, 결과. 주요 행동: 프로젝트 상세.
6. 프로젝트 상세 — 브리프, 문제, 전략, 과정, 주요 산출물, 미디어 갤러리, 결과/근거, 크레딧, 관련 프로젝트. 주요 행동: 유사 프로젝트 문의.
7. 프로세스 — 문의, 진단, 제안, 계약, 제작, 검수, 전달, 운영과 단계별 고객 참여. 주요 행동: 문의 시작.
8. 팀 목록 — 역할, 전문분야, 대표 프로젝트, 짧은 소개. 주요 행동: 팀 상세.
9. 팀 상세 — 관점, 경험, 역할, 담당 프로젝트, 글/강연. 주요 행동: 프로젝트 보기.
10. 인사이트 목록 — 글/리포트/영상의 주제·유형 필터와 관련 서비스. 주요 행동: 글 상세.
11. 인사이트 상세 — 본문, 작성자, 발행/개정일, 관련 프로젝트·서비스, 공유. 주요 행동: 문의.
12. 프로젝트 문의 — 유형, 목표, 문제, 범위, 예산, 일정, 참고 링크, 브리프/파일 첨부, 연락처·동의. 주요 행동: 문의 접수.

[필수 상태와 시스템 화면]
- 프로젝트·인사이트: 기본, 필터, 결과 없음, 미디어 로딩 실패.
- 문의: 파일 형식/용량 오류, 필수값 오류, 업로드 중, 접수 완료.
- 공통: 검색 결과, 404, 개인정보처리방침, 이용약관, 폼 완료, 빈 상태·오류.
```
