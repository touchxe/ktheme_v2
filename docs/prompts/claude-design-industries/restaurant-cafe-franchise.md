# 음식점/카페/프랜차이즈 전체 페이지 생성 프롬프트

```text
모두 테마의 음식점/카페/프랜차이즈 웹사이트 전체 페이지 세트를 하나의 연결된 프로젝트로 생성하라.

[입력값]
- 브랜드명: [브랜드명]
- 업체 유형: [음식점/카페/베이커리/프랜차이즈 본사/로컬 식음료]
- 적용 프리셋: [restaurant-menu/cafe-space/franchise-recruitment/local-food-brand]
- 핵심 메뉴·운영 형태: [대표 메뉴와 단일/다지점/가맹 여부]
- 메뉴·매장·가맹 자료: [제공 자료 또는 없음]

[실행 원칙]
- 제공된 모두 테마 디자인 규칙을 적용하고 별도의 스타일 규칙을 만들거나 설명하지 마라.
- 아래 페이지를 하나의 프로젝트 안에서 공통 내비게이션·메뉴·매장 컴포넌트로 연결해 모두 생성하라.
- 설명 출력보다 실제 페이지 프레임에 토큰을 우선한다. 한계가 있으면 장식 변형을 줄이고 페이지는 유지한다.
- 가격, 원산지, 알레르기, 매장시간, 가맹비·수익 수치는 제공 자료 없이는 창작하지 말고 예시/확인 필요로 표시한다.
- 핵심 흐름은 메뉴 탐색 → 매장 선택 → 예약이며, 가맹형이면 브랜드 검토 → 비용·절차 확인 → 가맹 문의도 동등하게 제공한다.

[생성할 페이지]
1. 홈 — 대표 메뉴, 공간, 가까운 매장, 브랜드 이야기, 후기, 소식, 예약과 가맹 진입. 주요 행동: 메뉴·매장 찾기·예약/가맹 문의.
2. 브랜드 이야기 — 시작, 맛/공간 철학, 원재료, 제조/조리 과정, 사람, 매장 경험. 주요 행동: 메뉴·매장 보기.
3. 메뉴 목록 — 카테고리·식이/알레르기 필터, 이미지, 가격, 원산지/알레르기, 판매·품절·시즌 상태. 주요 행동: 메뉴 상세.
4. 메뉴 상세 — 이미지, 설명, 구성/옵션, 가격, 원재료·알레르기, 추천 조합, 판매 매장. 주요 행동: 매장 찾기·예약.
5. 공간·갤러리 — 공간 사진, 좌석, 단체 가능, 유아/반려동물 정책, 접근성, 주차. 주요 행동: 매장 보기.
6. 매장 찾기 — 지역·서비스 필터, 지도/목록, 운영시간, 편의, 현재 영업 상태. 주요 행동: 매장 상세·길찾기.
7. 매장 상세 — 주소, 시간, 제공 메뉴/서비스, 공간 사진, 좌석·주차, 공지. 주요 행동: 예약·길찾기·전화.
8. 예약 — 지점, 날짜, 가능 시간, 인원, 좌석/목적, 요청사항, 연락처, 동의, 확인. 주요 행동: 예약 완료.
9. 창업·가맹안내 — 브랜드 경쟁력, 가맹 모델, 예상비용 항목, 지원, 개설 절차, 사례, FAQ와 수익 비보장 고지. 주요 행동: 가맹 문의.
10. 가맹문의 — 희망지역, 점포 보유 여부, 예산 범위, 경험, 희망 일정, 연락처, 동의. 주요 행동: 문의 접수.
11. 소식·FAQ — 신메뉴/행사/매장 공지 목록·상세, 예약·알레르기·운영·가맹 FAQ. 주요 행동: 메뉴·예약·문의.

[필수 상태와 시스템 화면]
- 메뉴·매장: 기본, 필터, 결과 없음, 판매중, 품절, 시즌 종료, 영업중/마감.
- 예약·문의: 가능/마감, 검증 오류, 전송 중, 완료, 취소 안내.
- 공통: 검색 결과, 404, 개인정보처리방침, 이용약관·예약 취소/환불정책, 폼 완료, 빈 상태·오류.
```
