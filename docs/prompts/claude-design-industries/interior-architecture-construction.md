# 인테리어/건축/시공 전체 페이지 생성 프롬프트

```text
모두 테마의 인테리어/건축/시공 업체 웹사이트 전체 페이지 세트를 하나의 연결된 프로젝트로 생성하라.

[입력값]
- 브랜드명: [업체명]
- 업체 유형: [인테리어/건축사/시공사/리모델링/조경]
- 적용 프리셋: [interior-residential/interior-commercial/architecture-project/construction-quote]
- 주력 공간·공정: [예: 주거 리모델링/상업공간]
- 프로젝트·팀·자격 자료: [제공 자료 또는 없음]

[실행 원칙]
- 제공된 모두 테마 디자인 규칙을 그대로 적용하고 스타일 설명을 반복하지 마라.
- 아래 모든 페이지를 공통 내비게이션과 프로젝트·서비스 컴포넌트로 연결한 실제 페이지 프레임으로 생성하라.
- 보고서 대신 페이지 제작에 토큰을 사용한다. 한계가 있으면 중복 이미지 변형과 긴 예시 문구를 줄이고 페이지는 유지한다.
- 프로젝트, 면적, 기간, 비용, 자격, 성과는 제공 자료가 없으면 사실처럼 만들지 말고 예시임을 표시한다.
- 핵심 흐름은 대표 프로젝트 탐색 → 서비스·과정·역량 검토 → 현장 정보와 파일을 첨부한 견적 문의다.

[생성할 페이지]
1. 홈 — 대표 프로젝트, 서비스, 전후 변화, 진행 과정, 팀, 후기, 견적 진입. 주요 행동: 프로젝트 보기·견적 문의.
2. 브랜드·회사 소개 — 미감/시공 철학, 팀, 연혁, 자격, 협력사, 대응 지역. 주요 행동: 프로젝트·팀 보기.
3. 서비스 목록 — 주거/상업/건축/조경 등 공간·공정별 범위, 포함/제외, 예상 기간. 주요 행동: 서비스 상세.
4. 서비스 상세 — 적합 대상, 제공 범위, 산출물, 진행 단계, 예상 일정, 비용 안내 방식, 관련 프로젝트. 주요 행동: 상담·견적.
5. 시공사례 목록 — 공간·평수·스타일·지역·서비스 필터, 대표 이미지, 범위, 기간. 주요 행동: 프로젝트 상세.
6. 프로젝트 상세 — 브리프, 기존 문제, 컨셉, 도면/배치, 전후 비교, 공정, 자재, 결과, 크레딧. 주요 행동: 유사 프로젝트 문의.
7. 전후·과정 갤러리 — 비교 슬라이더/쌍, 공정 단계, 기간과 촬영 조건, 관련 프로젝트. 주요 행동: 상세 보기.
8. 진행 프로세스 — 문의, 현장방문, 제안, 계약, 설계, 시공, 검수, A/S와 단계별 고객 준비사항. 주요 행동: 견적 시작.
9. 팀 목록 — 역할, 경력, 자격, 대표 프로젝트. 주요 행동: 구성원·프로젝트 보기.
10. 팀 상세 — 소개, 전문영역, 검증 가능한 자격, 담당 프로젝트, 협업 역할. 주요 행동: 프로젝트 상담.
11. 견적문의 — 공간유형, 위치, 면적, 현재 상태, 목표, 예산 범위, 희망일, 도면·현장사진·참고파일 첨부, 연락처·동의. 주요 행동: 견적 접수.
12. 오시는 길 — 상담 사무실, 주소, 주차, 상담 가능시간, 연락처. 주요 행동: 방문 예약·길찾기.

[필수 상태와 시스템 화면]
- 사례: 기본, 필터 적용, 결과 없음, 이미지 비교 전/후.
- 견적 폼: 파일 끌어놓기, 형식/용량 오류, 필수값 오류, 업로드 중, 접수 완료.
- 공통: 검색 결과, 404, 개인정보처리방침, 이용약관·계약/하자 안내, 폼 완료, 빈 상태·오류.
```
