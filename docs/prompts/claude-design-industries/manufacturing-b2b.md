# 제조/B2B 전체 페이지 생성 프롬프트

```text
모두 테마의 제조/B2B 기업 웹사이트 전체 페이지 세트를 하나의 연결된 프로젝트로 생성하라.

[입력값]
- 브랜드명: [회사명]
- 업체 유형: [장비/자동화·로봇/센서·IoT/에너지/설비/검사·안전/부품·소재]
- 적용 프리셋: [industrial-equipment/industrial-automation/industrial-energy/industrial-inspection]
- 핵심 제품군·적용산업: [3~6개]
- 제품 사양·인증·사례 자료: [제공 자료 또는 없음]

[실행 원칙]
- 기존 모두 테마 디자인 규칙을 적용하고 스타일 규칙을 새로 정의하거나 설명하지 마라.
- 아래 페이지 전체를 같은 IA와 재사용 컴포넌트로 연결한 실제 페이지 프레임으로 생성하라.
- 설명 출력보다 페이지 제작에 토큰을 우선한다. 한계가 있으면 장식과 중복 예시를 줄이고 페이지는 유지한다.
- 인증, 특허, 고객사, 성능 수치, 납품 성과를 창작하지 않는다. 자료가 없으면 명확한 예시 자리표시자로 만든다.
- 핵심 흐름은 현장 문제 → 제품/기술 탐색 → 사양·사례·인증 검토 → 자료 다운로드·견적 요청이다.

[생성할 페이지]
1. 홈 — 현장 문제, 제품군, 적용산업, 대표제품, 사례, 생산역량, 인증, 기술지원. 주요 행동: 제품 찾기·견적 문의.
2. 회사 소개 — 연혁, 조직, 생산능력, 품질정책, 연구개발, 글로벌 대응. 주요 행동: 설비·인증 보기.
3. 제품·기술 목록 — 제품군·용도·사양 필터, 모델 카드, 핵심 사양, 적용처, 비교 선택. 주요 행동: 제품 상세·비교.
4. 제품 상세 — 이미지/도면, 사양표, 모델·옵션, 적용환경, 인증, 다운로드, 적용사례, 문의. 주요 행동: 자료 다운로드·견적.
5. 제품 비교 — 선택 모델 2~4개의 사양, 옵션, 적용처, 인증, 문의 항목 비교. 주요 행동: 비교 모델 견적.
6. 적용산업 목록 — 산업별 문제, 적용 제품, 시스템 구성, 기대 성과의 근거 영역. 주요 행동: 산업 상세·사례.
7. 적용산업 상세 — 현장 조건, 문제, 권장 구성, 관련 제품·사례·자료. 주요 행동: 기술 상담.
8. 사례 목록 — 산업·제품·공정 필터, 현장 문제, 구성, 검증 가능한 결과. 주요 행동: 사례 상세.
9. 사례 상세 — 배경, 요구사항, 설계·납품 과정, 구성도, 결과 수치와 출처, 관련 제품. 주요 행동: 유사 프로젝트 견적.
10. 설비현황 — 공장·설비 사진, 장비명, 역할, 생산·검사 능력, 품질 흐름. 주요 행동: 방문·문의.
11. 인증·특허 라이브러리 — 종류·기관·유효상태 필터, 문서 썸네일, 발급기관, 유효기간, 원본 보기. 주요 행동: 문서 확인.
12. 기술자료 목록 — 제품·유형·언어·버전 필터, 도면/카탈로그/매뉴얼. 주요 행동: 자료 상세·다운로드.
13. 기술자료 상세 — 설명, 대상 모델, 버전 이력, 미리보기, 관련 제품, 다운로드. 주요 행동: 다운로드.
14. 견적문의 — 제품/모델, 수량, 요구사양, 적용환경, 일정, 회사정보, 도면·요구서 첨부, 동의. 주요 행동: 견적 접수.
15. A/S·기술지원 — 지원 범위, 보증, 접수절차, 부품·매뉴얼, 긴급 연락, 지원 폼. 주요 행동: 지원 접수.
16. 오시는 길 — 본사·공장·영업소 선택, 주소, 방문/물류 안내, 연락처. 주요 행동: 길찾기·전화.

[필수 상태와 시스템 화면]
- 목록·비교: 기본, 필터, 결과 없음, 비교 미선택/최대 초과.
- 다운로드·견적: 권한/리드 폼, 파일 오류, 검증 오류, 업로드 중, 접수 완료.
- 공통: 검색 결과, 404, 개인정보처리방침, 이용약관, 폼 완료, 빈 상태·자료 연동 오류.
```
