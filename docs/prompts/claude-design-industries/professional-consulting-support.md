# 전문서비스/컨설팅/창업지원 전체 페이지 생성 프롬프트

```text
모두 테마의 전문서비스/컨설팅/창업지원 기관 웹사이트 전체 페이지 세트를 하나의 연결된 프로젝트로 생성하라.

[입력값]
- 회사·기관명: [이름]
- 업체 유형: [경영컨설팅/창업지원/액셀러레이터/인증자문/시장조사/조직·디지털전환]
- 적용 프리셋: [expert-consulting/expert-startup-support/expert-assessment/expert-public-program]
- 핵심 대상·문제: [고객 단계와 문제]
- 서비스·전문가·사례·지원사업 자료: [제공 자료 또는 없음]

[실행 원칙]
- 제공된 모두 테마 디자인 규칙을 적용하고 디자인 규칙을 새로 작성하지 마라.
- 아래 페이지 전체를 공통 내비게이션과 서비스·진단·사례 컴포넌트로 연결한 실제 페이지 프레임으로 생성하라.
- 설명 보고서를 생략하고 페이지 생성에 토큰을 우선한다. 한계가 있으면 장식과 중복 예시를 줄이고 페이지는 유지한다.
- 성과, 고객사, 지원금, 자격, 선정 가능성, 진단 정확도는 자료 없이는 창작하지 말고 근거/면책 영역을 둔다.
- 핵심 흐름은 문제 확인 → 자가진단 → 결과·추천 서비스 → 사례/전문가 검토 → 상담 신청이다.

[생성할 페이지]
1. 홈 — 문제별 진입, 서비스, 자가진단, 전문가, 사례, 절차, 패키지, 자료. 주요 행동: 진단 시작·상담.
2. 회사·기관 소개 — 미션, 연혁, 조직, 파트너, 인증, 검증 가능한 성과와 출처. 주요 행동: 서비스·전문가 보기.
3. 서비스 목록 — 문제·성장단계·대상 필터, 산출물, 기간, 가격/문의. 주요 행동: 서비스 상세.
4. 서비스 상세 — 대상 문제, 제공/제외 범위, 방법, 산출물, 기간, 전문가, 사례, 패키지. 주요 행동: 상담 신청.
5. 자가진단 — 시작 안내, 질문, 단일/복수 선택, 조건부 문항, 진행률, 이전/다음, 저장/동의, 제출. 주요 행동: 결과 보기.
6. 진단 결과 — 유형/점수, 영역별 해석, 근거·면책, 우선순위, 추천 서비스·자료, 결과 저장/공유. 주요 행동: 상담·추천 보기.
7. 전문가 목록 — 전문영역, 경력, 프로젝트, 자격, 상담 분야. 주요 행동: 전문가 상세.
8. 전문가 상세 — 약력, 전문분야, 검증 가능한 자격, 프로젝트, 자료/강연, 담당 서비스. 주요 행동: 상담.
9. 프로젝트·사례 목록 — 업종·규모·서비스 필터, 문제, 접근, 검증 가능한 결과. 주요 행동: 사례 상세.
10. 사례 상세 — 배경, 진단, 실행, 산출물, 결과와 근거, 관련 서비스·전문가. 주요 행동: 유사 문제 상담.
11. 진행절차 — 진단, 제안, 계약, 수행, 보고, 후속지원과 고객 준비사항. 주요 행동: 상담 시작.
12. 패키지 비교 — 대상, 포함 항목, 기간, 가격/문의, 추천 조건, 산출물, 제외 범위. 주요 행동: 패키지 상담.
13. 자료실 목록 — 보고서, 지원사업, 템플릿, 도구의 유형·주제·마감일 필터. 주요 행동: 자료 상세.
14. 자료 상세 — 요약, 대상, 목차/미리보기, 버전, 마감/출처, 파일, 관련 서비스. 주요 행동: 다운로드·상담.
15. 상담신청 — 조직, 단계, 문제, 목표, 예산/일정, 희망 서비스, 자료 첨부, 연락처·동의. 주요 행동: 접수.
16. FAQ — 지원범위, 비용, 기간, 보안, 계약/환불, 지원사업 유의. 주요 행동: 상담.
17. 오시는 길 — 주소, 주차, 온라인 미팅, 운영시간. 주요 행동: 방문·미팅.

[필수 상태와 시스템 화면]
- 자가진단: 시작, 진행, 미응답 오류, 조건부 분기, 제출 중, 결과, 결과 생성 실패.
- 목록·비교·폼: 필터/결과 없음, 선택 전, 첨부 오류, 접수 완료.
- 공통: 검색 결과, 404, 개인정보처리방침, 이용약관·컨설팅 면책, 폼 완료, 빈 상태·오류.
```
