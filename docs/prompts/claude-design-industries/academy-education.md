# 학원/교육기관 전체 페이지 생성 프롬프트

```text
모두 테마의 학원/교육기관 웹사이트 전체 페이지 세트를 하나의 연결된 프로젝트로 생성하라.

[입력값]
- 브랜드명: [기관명]
- 업체 유형: [입시학원/직업·평생교육/온라인교육/공공·민간 교육기관]
- 적용 프리셋: [academy-course/academy-instructor/academy-admission/education-institution]
- 교육 대상과 목표: [예: 중학생 입시/직무 전환/자격 취득]
- 과정·강사·일정 자료: [제공 자료 또는 없음]

[실행 원칙]
- 제공된 모두 테마 디자인 규칙을 그대로 사용하고 디자인 규칙을 반복 설명하지 마라.
- 아래 전 페이지를 같은 프로젝트 안에 공통 내비게이션·컴포넌트로 연결한 실제 페이지 프레임으로 생성하라.
- 보고서는 생략하고 화면 생성에 토큰을 사용한다. 한계가 있으면 샘플 콘텐츠와 장식 변형을 줄이되 페이지는 생략하지 않는다.
- 확인되지 않은 합격률, 취업률, 자격, 수강생 성과는 창작하지 말고 예시/검증 필요로 표시한다.
- 핵심 흐름은 대상·목표별 과정 탐색 → 과정·강사·개강 일정 확인 → 상담·수강 신청이다.

[생성할 페이지]
1. 홈 — 대상별 과정, 다음 개강, 대표 강사진, 후기, 시설/온라인 학습, 자료, 상담 CTA. 주요 행동: 과정 찾기·수강 상담.
2. 기관 소개 — 교육 철학, 운영 주체, 연혁, 시설, 인증, 학습 지원. 주요 행동: 과정 보기.
3. 교육과정 목록 — 대상·목표·기간·방식 필터, 과정 카드, 일정, 수강료, 모집/마감 상태. 주요 행동: 과정 상세.
4. 과정 상세 — 학습목표, 대상/선수조건, 커리큘럼, 강사, 일정, 준비물, 평가·수료, 가격·환불, FAQ. 주요 행동: 수강 신청·상담.
5. 강사진 목록 — 전문분야, 경력, 담당 과정, 소개 미디어. 주요 행동: 강사 상세.
6. 강사 상세 — 경력, 자격, 교육 철학, 담당 과정, 출강 일정, 후기. 주요 행동: 담당 과정 보기.
7. 일정·개강 — 달력/목록, 과정, 날짜·시간, 방식/장소, 정원, 신청 가능·마감·대기 상태. 주요 행동: 일정 선택.
8. 수강 신청 — 과정/회차 선택, 신청자 정보, 현재 수준, 결제 또는 상담 방식, 약관·개인정보 동의, 확인. 주요 행동: 신청 완료.
9. 수강후기 목록 — 과정·목표별 필터, 후기 맥락, 사진/영상, 결과 과장 방지 고지. 주요 행동: 과정 보기.
10. 후기 상세 — 수강 배경, 선택 과정, 학습 경험, 변화, 개인차 고지, 관련 과정. 주요 행동: 과정 상담.
11. 자료실 목록 — 커리큘럼, 학습자료, 입학자료의 분류, 버전, 파일 형식. 주요 행동: 자료 상세.
12. 자료 상세 — 설명, 미리보기, 버전/게시일, 관련 과정, 다운로드 조건. 주요 행동: 다운로드.
13. 입학·수강상담 — 목표, 현재 수준, 희망 일정/방식, 관심 과정, 연락처, 동의. 주요 행동: 상담 접수.
14. 공지·FAQ — 개강/휴강 공지 목록·상세, 환불, 준비물, 수료, 온라인 접속 FAQ. 주요 행동: 과정·상담.
15. 오시는 길 — 캠퍼스/지점, 지도, 교통, 주차, 교실, 상담시간. 주요 행동: 길찾기.

[필수 상태와 시스템 화면]
- 목록·달력: 기본, 필터, 결과 없음, 모집 예정, 신청 가능, 마감, 대기 접수.
- 신청/상담: 기본, 검증 오류, 전송/결제 중, 완료, 실패·재시도.
- 공통: 검색 결과, 404, 개인정보처리방침, 이용약관·환불정책, 폼 완료, 빈 상태·오류. 계정형 온라인교육이면 로그인·회원가입·내 학습 진입도 포함한다.
```
