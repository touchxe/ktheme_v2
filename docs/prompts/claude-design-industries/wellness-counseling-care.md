# 웰니스/상담/돌봄 전체 페이지 생성 프롬프트

```text
모두 테마의 웰니스/상담/돌봄 웹사이트 전체 페이지 세트를 하나의 연결된 프로젝트로 생성하라.

[입력값]
- 브랜드·센터명: [이름]
- 업체 유형: [필라테스·요가/심리상담/비의료 코칭/운동센터/시니어돌봄/명상]
- 적용 프리셋: [wellness-movement/wellness-counseling/wellness-senior-care/wellness-multi-branch]
- 주요 이용 목적·프로그램: [3~8개]
- 전문가·지점·일정 자료: [제공 자료 또는 없음]

[실행 원칙]
- 제공된 모두 테마 디자인 규칙을 그대로 적용하고 디자인 규칙을 재작성하지 마라.
- 아래 모든 페이지를 공통 내비게이션과 프로그램·전문가·예약 컴포넌트로 연결한 실제 페이지 프레임으로 생성하라.
- 설명문보다 페이지 생성에 토큰을 우선한다. 한계가 있으면 장식 변형과 중복 샘플 문구를 줄이고 페이지는 유지한다.
- 자격, 치료·개선 효과, 후기, 가격, 가능 일정은 제공 자료가 없으면 사실처럼 만들지 않는다. 의료행위 여부와 긴급지원 한계를 명확히 구분한다.
- 핵심 흐름은 이용 목적 탐색 → 프로그램·전문가·범위 확인 → 안전한 상담/방문 예약이다.

[생성할 페이지]
1. 홈 — 목적별 탐색, 대표 프로그램, 전문가, 이용절차, 공간, 가격 안내, 후기, 안전 고지. 주요 행동: 상담·예약.
2. 센터 소개 — 철학, 제공/제외 범위, 운영 주체, 시설, 접근성, 지점. 주요 행동: 프로그램·지점 보기.
3. 프로그램 목록 — 목적·강도·대상·지점 필터, 시간, 빈도, 가격/상담, 담당자. 주요 행동: 프로그램 상세.
4. 프로그램 상세 — 대상, 목표, 제공 범위, 과정, 일정, 담당자, 준비/제한, 가격, 고지. 주요 행동: 상담·예약.
5. 전문가 목록 — 전문분야·지점 필터, 검증 가능한 자격, 경력, 가능 프로그램, 상담 방식. 주요 행동: 전문가 상세.
6. 전문가 상세 — 약력, 자격, 접근 방식, 담당 프로그램, 일정, 익명 후기, 전문범위. 주요 행동: 담당자 지정 상담.
7. 이용절차 — 첫 문의, 초기상담, 적합성 확인, 배정, 이용, 평가/종료, 외부기관 연계. 주요 행동: 상담 시작.
8. 공간·시설 — 상담실/운동공간, 편의, 접근성, 위생·안전, 지점 연결. 주요 행동: 지점 보기.
9. 가격·상담 안내 — 프로그램/회기, 포함 항목, 시작가/문의, 패키지 비교, 변경·환불. 주요 행동: 상담.
10. 상담·예약 — 목적, 희망 방식/지점/담당자, 날짜·가능 시간, 연락처, 최소한의 사전정보, 동의, 긴급안내. 주요 행동: 접수.
11. 후기 목록 — 프로그램·이용 맥락 필터, 익명 인용, 승인, 효과 비보장 고지. 주요 행동: 프로그램 보기.
12. 후기 상세 — 이용 배경, 과정 경험, 변화에 대한 개인 서술, 관련 프로그램, 개인차 고지. 주요 행동: 상담.
13. FAQ·중요 고지 — 제공 범위, 의료행위 여부, 긴급 연락처, 취소, 개인정보, 보호자, 접근성. 주요 행동: 상담·외부 도움.
14. 지점 찾기 — 지도/목록, 운영시간, 프로그램, 전문가, 접근성, 현재 운영 상태. 주요 행동: 지점 상세.
15. 지점 상세 — 주소, 시간, 공간, 프로그램, 전문가, 주차/접근성. 주요 행동: 이 지점 예약.

[필수 상태와 시스템 화면]
- 예약: 선택 전, 가능, 마감, 휴무, 검증 오류, 전송 중, 완료.
- 민감 요청: 긴급 위험 안내, 최소정보 원칙, 동의 미선택, 안전한 이탈 경로.
- 공통: 검색 결과, 404, 개인정보처리방침, 이용약관·취소/환불정책, 폼 완료, 빈 상태·예약 오류.
```
