# 가평교회 디자인 시스템

가평교회(GAPYEONG CHURCH) 웹사이트를 위한 디자인 시스템입니다. 예배·공동체·양육·미디어를 안내하는 한국어 교회 웹사이트의 디자인 토큰, 재사용 컴포넌트, 전체 화면 UI 킷을 담고 있습니다.

> **콘셉트**: "말씀이 머무는 자리, 은혜가 흐르는 공동체." 절제된 잉크 톤 위에 브랜드 블루로 강조를 주는, 잡지/뉴스룸 감성의 신뢰감 있는 디자인.

## 출처 (Sources)
이 시스템은 프로젝트 내 기존 산출물에서 추출했습니다:
- `디자인 라이브러리.html` — 기존 디자인 라이브러리 문서 (토큰·컴포넌트·섹션 전체)
- `index.html` — 홈(랜딩) 페이지
- `worship.html`, `training.html`, `lecture.html`, `library.html`, `교회 비전.html` — 서브 페이지
- `서브페이지 히어로 시안.html`, `핵심가치 원형 시안.html` — 히어로/섹션 시안
- `assets/logo.png` — 교회 로고 마크

## CONTENT FUNDAMENTALS — 콘텐츠/카피

- **언어**: 한국어 우선. 영문은 보조 라벨/오버라인으로만 사용 (`GAPYEONG CHURCH`, `SUNDAY WORSHIP · VOL 04`, `2026 SPRING SERIES`).
- **호칭/톤**: 따뜻하고 초대하는 어조. 회중을 "여러분"으로 부르고, 격식 있는 존댓말("~합니다", "초대합니다")을 사용. 명령형보다 권유형.
  - 예) "예배와 말씀, 그리고 공동체 안에서 삶이 회복되는 자리로 여러분을 초대합니다."
- **카피 길이**: 헤드라인은 짧고 운율 있게, 두 줄 대구 형태를 즐겨 씀.
  - 예) "말씀이 머무는 자리, / 은혜가 흐르는 공동체."  ·  "예배 안으로"  ·  "머무름의 영성"
- **메타 표기**: 설교/예배 정보는 사실 위주로 간결하게. 본문은 성경 약어(`시편 23:1–6`), 날짜는 `2026.04.26`, 설교자는 직분 포함(`정한결 담임목사`).
- **오버라인 라벨**: 영문 대문자 + 넓은 자간 + 가운뎃점(·) 구분. 시리즈/회차를 표기 (`2026 SPRING SERIES · VOL. 04`).
- **이모지**: 사용하지 않음. 상태 표시는 작은 색 점(●)이나 LIVE 뱃지로 대체.
- **버튼 카피**: 동사 위주의 짧은 행동 유도. "이번 주 설교 보기", "예배 시간 안내", "새가족 등록", "다시보기".

## VISUAL FOUNDATIONS — 비주얼 파운데이션

### 색
- **잉크(중성)** 계열이 텍스트와 어두운 면을 지배: `--ink-900 #0E1320`가 본문 텍스트·히어로·푸터 배경. 600~900으로 단계 구성.
- **브랜드 블루** `--brand-600 #2A4FD6`가 링크·주요 액션·강조. 500/600/700 3단계.
- **액센트 레드** `--accent-red #E23B3B`는 오직 LIVE/긴급 표시에만 절제해서 사용.
- **면**: 흰색(`--white`)이 기본 페이지, 연회색(`--paper #F4F5F7`)이 보조 면, `--line #E5E7EB`가 경계.
- **카테고리 컬러**: 설교/예배 분류를 위한 6색 (주일=블루, 수요=에메랄드, 청년=앰버, 새벽=로즈, 유년부=바이올렛, 기타=스카이). 모두 600 명도로 통일.

### 타이포그래피
- **Pretendard Variable** 단일 가족. 한글 가독성과 가변 굵기.
- 큰 텍스트일수록 `letter-spacing: -0.01em ~ -0.02em`로 조여줌. 본문 행간은 넉넉하게 `1.85`.
- 굵기 대비가 핵심: 헤딩/카피는 **800(extrabold)**, 본문은 400, 라벨은 700.
- 스케일: Display 56 · H1 44 · H2 22~26 · H3 20 · Body 14~15 · Caption 12 · Overline 11.

### 레이아웃 & 간격
- 컨테이너 `max-width: 1240px`, 좌우 패딩 24px. 문서/라이브러리는 1320px.
- **12컬럼 그리드 + gap 24px**. 히어로는 7/5 비율 분할을 즐겨 씀.
- 고정(sticky) 헤더 높이 72px, 상단 유틸리티 바 36px. 섹션 상하 여백 56~80px.

### 면/카드/경계
- 카드: 흰 배경 + `--radius-xl(16px)` + 아주 옅고 멀리 퍼지는 그림자 `--shadow-card`(`0 18px 36px -24px`). 무거운 그림자는 피함.
- 경계선은 1px `--line`. 강조 경계는 `--ink-900` 1px (아웃라인 버튼·강조 카드).
- 라운드: 뱃지 3px, 입력 8px, 타일 12px, 카드 16px, 버튼은 **알약형(full)**.

### 버튼 (요약 — 상세는 components/)
- Primary Dark: `--ink-900` 배경 + 흰 글씨, 알약형.
- Primary Brand: `--brand-600` 배경.
- Outline: `--ink-900` 1px 테두리, hover 시 채워짐(반전).
- Ghost/Subtle: `--line` 테두리, hover 시 `--paper`.

### 배경 & 이미지
- 히어로는 **풀블리드 사진** 위에 좌→우 어두운 그라데이션(`--hero-fade`)을 얹어 흰 텍스트 가독성 확보. 사진 위 텍스트는 항상 왼쪽 정렬.
- 이미지 톤: 자연광/따뜻한 사진 + opacity 0.7로 살짝 가라앉힘.
- 장식 그래픽: 중앙 로고를 둘러싼 **오비트/허브**(회전 궤도 위 아이콘), **겹친 원형 가치 블록** 등 절제된 기하 모티프. 직접 그린 복잡한 일러스트는 쓰지 않음.

### 모션 & 상태
- 전환은 짧고 부드럽게: `--dur-base 0.28s`, `--ease-out cubic-bezier(.2,.8,.2,1)`.
- hover: 색 어두워지기 또는 반전(아웃라인), 면 버튼은 `--paper`로. press 시 별도 축소 없음.
- 라이브/재생: 펄스 링 애니메이션(`pulse`), 스켈레톤 시머, 토스트 슬라이드인.
- `prefers-reduced-motion` 존중 — 궤도/펄스 애니메이션 정지.

### 투명도 & 블러
- 고정 헤더는 `rgba(white, .95)` + `backdrop-blur`. 다크 면 위 텍스트는 흰색 75% 투명도.

## ICONOGRAPHY — 아이콘

- **선형(라인) 아이콘** 일관 사용. `viewBox="0 0 24 24"`, `stroke-width: 2`(강조 2.2), 라운드 캡/조인, `fill: none`. 재생 버튼 등 일부만 `fill`.
- 스타일은 **Lucide / Feather** 계열과 동일. CDN으로 Lucide를 끌어와 쓰거나, 인라인 SVG로 직접 그려도 동일한 규격(stroke 2, round cap)을 지킴.
- 색은 `currentColor` 상속. 기본 `--ink-700`, hover 시 `--ink-900`.
- **이모지·유니코드 아이콘은 쓰지 않음.** 상태 점만 `<span>` 색 원으로 표현.
- 로고: `assets/logo.png` (640×594). 헤더에서는 텍스트 로고타입과 함께 사용.
