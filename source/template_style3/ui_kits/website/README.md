# 가평교회 웹사이트 UI 킷

가평교회 공식 웹사이트의 핵심 화면을 디자인 시스템 컴포넌트로 재현한 킷입니다.

## 화면
- **홈** (`HomeScreen.jsx`) — 상단 유틸리티 바, 풀블리드 히어로(설교 시리즈), 필터 가능한 최근 설교 다시보기.
- **예배 / 새가족 등록** (`WorshipScreen.jsx`) — 페이지 히어로, 예배 시간 안내 리스트, 새가족 등록 폼.
- 공통: `Header.jsx`(sticky 내비 + LIVE 뱃지), `Footer.jsx`(다크 4컬럼 푸터).

## 상호작용
- 헤더의 "예배" 탭을 누르면 예배/등록 화면으로, 로고를 누르면 홈으로 전환됩니다.
- 최근 설교 섹션의 필터 칩(전체/주일/수요/청년/새벽)으로 목록이 실시간으로 걸러집니다.

## 구성
컴포넌트 프리미티브(`Button`, `Badge`, `Card`, `SermonCard`, `FilterChip`, `Input`, `Select`)를 조합했습니다. 번들 네임스페이스는 `index.html`에서 자동 감지해 `window.__NS`로 통일합니다.

## 원본 출처
프로젝트 루트의 `index.html`(홈), `worship.html` 등 기존 페이지를 기반으로 재현했습니다. 히어로 사진은 Unsplash 플레이스홀더이며, 실제 사진/주소/연락처로 교체가 필요합니다.
