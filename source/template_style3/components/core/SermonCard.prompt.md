설교/예배 영상 목록 한 줄. 다시보기 리스트, 최근 설교 섹션에 반복 사용.

```jsx
<SermonCard category="주일" title="머무름의 영성을 세우기로"
  speaker="정한결 목사" date="2026.04.26"
  image="https://images.unsplash.com/photo-1507692049790-de58290a4334" />
```

- `category`로 분류 라벨 색이 자동 결정됨(주일=블루, 수요=에메랄드 등).
- 썸네일에는 항상 재생 마크가 얹힘. 여러 개를 `divide`(경계선)로 묶어 리스트 구성.
