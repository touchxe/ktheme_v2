## 1. 현재 프로젝트 상태 분석

### 프로젝트 개요
- **이름**: 케이테마_v2 (K-theme)
- **유형**: Next.js 14.2.0 (App Router) + WordPress Headless CMS
- **대상**: 교회 웹사이트 (교회소개, 예배/말씀, 사역/공동체, 교회소식, 새가족 안내)
- **디자인 시스템**: Linear.app 기반 커스텀 (`docs/DESIGN.md`, `tailwind.config.ts`에 매핑 완료)

### 누락/미완료 항목 (심각도 순)

#### 🔴 Critical (프로젝트 진행 불가)
1. **`app/` 디렉토리 없음** — Next.js 14 App Router 프로젝트인데 `app/` 디렉토리가 전혀 없습니다.
   - `app/layout.tsx` (루트 레이아웃)
   - `app/page.tsx` (랜딩 페이지)
   - `app/globals.css` (글로벌 스타일 + CSS 변수)
   - `app/layout.tsx`에 메타데이터 설정

2. **Next.js 의존성 설치 불명** — `node_modules/` 존재 여부 확인 필요

#### 🟠 High (핵심 기능 누락)
3. **WordPress 데이터 페칭 레이어 없음** — Next.js에서 WP REST API를 호출하는 레이어 부재
   - API 클라이언트 유틸리티
   - 타입 정의 (Post, Page, Sermon, Media 등)
   - React Server Components용 데이터 페칭 함수

4. **컴포넌트 인프라 없음** — `components/` 디렉토리 부재
   - `components/marketing/Hero.tsx`
   - `components/layout/Header.tsx`
   - `components/layout/Footer.tsx`
   - `components/ui/Button.tsx`, `Card.tsx` 등

5. **테스트 인프라 없음** — `__tests__/`, `e2e/` 디렉토리 부재
   - Vitest 설정 확인 필요
   - Playwright 설정 확인 필요

#### 🟡 Medium (BMAD 산출물)
6. **`docs/superpowers/plans/` 비어 있음** — 스토리 구현을 위한 상세 계획 없음
7. **`docs/superpowers/specs/` 비어 있음** — 브레인스토밍 산출물 없음
8. **BMAD 스토리가 예시 템플릿 상태** — `story-1.1-example-landing-hero.md`가 예시(draft) 상태

#### 🟢 Low (기타)
9. **`.env.local` 설정 확인 필요** — WP API URL, 인증 정보 등
10. **WordPress 스크립트 실행 상태 불명확** — `setup-wp-pages.js`, `insert_demo.php`가 실제로 실행되었는지 확인 필요

## 2. 발견된 문제점

### 구조적 문제
- Next.js App Router 프로젝트인데 `app/` 디렉토리가 없어 프로젝트 자체가 실행 불가능합니다.
- `pnpm dev`를 실행해도 Next.js 기본 파일이 없어 오류가 발생할 것입니다.

### 데이터 문제
- `nav-ids.json`은 존재하므로 네비게이션 스크립트는 실행됨
- 그러나 페이지 생성 및 데모 콘텐츠 삽입 스크립트가 실행되었는지는 알 수 없음

### 문서 문제
- `docs/superpowers/plans/`와 `specs/`가 비어 있어 BMAD Layer 2 산출물이 없습니다.
- `_bmad-output/stories/`에 있는 스토리가 예시 템플릿 상태입니다.

### 옵션 A: 프로젝트 부트스트랩부터 시작 (권장)
현재 프로젝트는 `app/` 디렉토리가 없어 실행 자체가 불가능합니다. 따라서 다음 순서로 진행하는 것을 권장합니다:

1. **Worktree 생성**: `pnpm wt:add story-bootstrap`
2. **Phase 0 실행**: `app/` 디렉토리 및 기본 파일 생성
3. **Phase 1 실행**: WordPress 연동 레이어 구축
4. **Phase 2-3 실행**: 컴포넌트 및 페이지 구현

WP 데이터가 이미 존재하는지 먼저 확인하고, Next.js 부트스트랩과 병렬로 진행합니다.

### 옵션 C: BMAD 문서부터 정리
`docs/superpowers/`와 `_bmad-output/stories/`를 먼저 정리한 후 구현을 시작합니다. 그러나 현재 프로젝트는 실행조차 불가능한 상태이므로 이것은 부적절해 보입니다.
