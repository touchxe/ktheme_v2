## 현재 구조 분석

`templates/page-about.html` 현재 상태:

```html
<!-- wp:template-part {"slug":"header","area":"header"} /-->

<!-- wp:shortcode -->[modutheme_page_hero]<!-- /wp:shortcode -->          ← PHP 단축코드 → 블록 에디터 편집 불가

<!-- wp:pattern {"slug":"modutheme/about-intro-01"} /-->             ← 템플릿에 하드코딩 → 블록 에디터에서 제거/이동 불가

<!-- wp:group {"layout":{"type":"constrained"}} -->
  <div class="wp-block-group modu-section bg-secondary">
    <div class="modu-container">
      <!-- wp:post-content ... /-->                                ← 유일한 블록 에디터 가능 영역 (좁음)
    </div>
  </div>
<!-- /wp:group -->

<!-- wp:pattern {"slug":"modutheme/worship-times-01"} /-->           ← 템플릿에 하드코딩 → 블록 에디터 편집 불가

<!-- wp:template-part {"slug":"footer","area":"footer"} /-->
```

**문제**: 페이지 콘텐츠의 80%가 템플릿 레벨 하드코딩. WP 관리자 > 페이지 편집 시 빈 `post-content`만 보임.

## 실행 계획

### Phase 1: Template 단순화 (핵심)

**대상 파일**: `templates/page-about.html`

**변경 내용**:
- `[modutheme_page_hero]` 단축코드 → **제거**
- `about-intro-01` 패턴 참조 → **제거**
- `worship-times-01` 패턴 참조 → **제거**
- `post-content` 주변의 `modu-section bg-secondary` + `modu-container` 래퍼 → **제거** (full-width 제어를 위해)
- 최종 템플릿은 **헤더 + post-content(100% wide) + 푸터**만 남김

**변경 후 예상 구조**:
```html
<!-- wp:template-part {"slug":"header","area":"header"} /-->

<!-- wp:group {"tagName":"main","layout":{"type":"default"}} -->
<main class="wp-block-group">
  <!-- wp:post-content {"layout":{"type":"constrained","contentSize":"1280px"}} /-->
</main>
<!-- /wp:group -->

<!-- wp:template-part {"slug":"floating-buttons"} /-->
<!-- wp:template-part {"slug":"footer","area":"footer"} /-->
```

### Phase 2: 블록 패턴으로 재구성

템플릿에서 제거한 요소들은 사용자가 블록 에디터에서 **패턴 삽입**으로 직접 넣을 수 있게 제공:

| 기존 요소 | 블록 패턴 slug | 상태 |
|---|---|---|
| 페이지 히어로 | `modutheme/page-hero` | **신규 등록 필요** (현재는 PHP `parts/page-hero.php`만 존재) |
| 교회 소개 (비전/통계) | `modutheme/about-intro-01` | ✅ 이미 등록됨 |
| 예배 시간 안내 | `modutheme/worship-times-01` | ✅ 이미 등록됨 |

**신규 작업**: `parts/page-hero.php`를 블록 패턴으로 포팅하거나, `core/cover` + `core/group` 블록 조합으로 사용자가 직접 만들 수 있게 가이드.

### Phase 3: about 페이지 콘텐츠 초기 구성

WP 관리자에서 `about` 페이지를 블록 에디터로 열고, 기본 콘텐츠를 미리 조립해두기 (선택적):

1. **히어로 블록**: `core/cover` 또는 커스텀 그룹 블록으로 교회소개 히어로 생성
2. **소개 패턴**: `about-intro-01` 패턴 삽입
3. **에디터 자유 영역**: 목사 인사말, 연혁, 조직도 등 (`core/heading`, `core/paragraph`, `core/image`, `core/columns` 등)
4. **예배 시간 패턴**: `worship-times-01` 패턴 삽입 (하단)

### Phase 4: theme.json 커스텀 템플릿 확인/등록

`theme.json`의 `customTemplates` 섹션에 `page-about`가 등록되어 있는지 확인:

```json
{
  "customTemplates": [
    {
      "name": "page-about",
      "title": "교회소개",
      "postTypes": ["page"]
    }
  ]
}
```

만약 미등록이면 WP 관리자 > 페이지 속성 > 템플릿에서 "교회소개" 선택 불가.

### Phase 5: Customizer fallback 히어로 제어

히어로를 블록 에디터로 완전히 전환하면, `parts/page-hero.php`의 fallback 데이터 테이블(`$modutheme_hero_defaults['about']`)은 더 이상 사용되지 않음.

**대안** (2가지 중 선택 필요):
- **A) 히어로도 블록 에디터로 전환**: `page-hero.php` fallback 제거, 블록 패턴으로 대체
- **B) 히어로는 PHP 유지, 나머지만 블록**: 템플릿에 `[modutheme_page_hero]`는 남기고, `about-intro-01` + `worship-times-01`만 제거

> **질문**: 히어로 영역(제목/부제/브레드크럼)도 블록 에디터에서 편집하게 할까요, 아니면 PHP 자동 생성을 유지할까요?

### Phase 6: 검증

| 검증 항목 | 방법 |
|---|---|
| about 페이지 블록 에디터 정상 로드 | WP 관리자 > 페이지 > 교회소개 > 편집 |
| 패턴 삽입 메뉴에 `modutheme/*` 패턴 표시 | 블록 인서터 > 패턴 탭 > ModuTheme 카테고리 |
| 저장 후 프론트 렌더링 일치 | `/about` 접속 → HTML 구조 확인 |
| 모바일/태블릿 반응형 유지 | 브라우저 devtools 375px/768px/1440px |
| GSAP 애니메이션 정상 작동 | `data-modu-animate` 속성 요소 확인 |

## 확정된 실행 계획

### Phase 1: Template 단순화

**대상**: `templates/page-about.html`

**변경 전**:
- `[modutheme_page_hero]` 단축코드
- `about-intro-01` 패턴 참조
- `worship-times-01` 패턴 참조
- `post-content` 주변 래퍼 (`modu-section bg-secondary` + `modu-container`)

**변경 후**:
```html
<!-- wp:template-part {"slug":"header","area":"header"} /-->

<!-- wp:group {"tagName":"main","layout":{"type":"default"}} -->
<main class="wp-block-group">
  <!-- wp:post-content {"layout":{"type":"constrained","contentSize":"1280px"}} /-->
</main>
<!-- /wp:group -->

<!-- wp:template-part {"slug":"floating-buttons"} /-->
<!-- wp:template-part {"slug":"footer","area":"footer"} /-->
```

### Phase 2: about 전용 히어로 블록 패턴 신규 등록

**신규 파일**: `patterns/hero-about-01.php`

**구성**: `core/group` 블록 기반, `bg-church-navy` 배경 + 십자가 도트 패턴 + 영문 레이블 + 한글 제목 + 부제목 + 브레드크럼

**특징**:
- `page-hero.php`의 about fallback 데이터를 블록 마크업으로 변환
- 사용자가 블록 에디터에서 직접 문구/색상 수정 가능
- `data-modu-animate="fade-up"` 속성 유지 (GSAP 연동)
- `modu-container` + `max-w-2xl` 레이아웃 적용

### Phase 3: about 페이지 콘텐츠 초기 조립 (WP 관리자)

`about` 페이지의 `post_content` 필드를 블록 마크업으로 미리 구성:

```
[최상단]
  └─ hero-about-01 패턴 삽입

[중앙]
  └─ about-intro-01 패턴 삽입
  └─ (에디터 자유 영역: 목사 인사말, 연혁, 조직도 등)

[하단]
  └─ worship-times-01 패턴 삽입
```

**작업 방법**: WP 관리자 > 페이지 > 교회소개 > 편집 → 블록 인서터 > 패턴 > ModuTheme 카테고리에서 순차 삽입

### Phase 4: theme.json 커스텀 템플릿 확인

`theme.json` 내 `customTemplates` 배열에 `page-about` 등록 여부 확인:
- **미등록 시**: `"name": "page-about", "title": "교회소개", "postTypes": ["page"]` 추가
- **등록 시**: 변경 없이 통과

### Phase 5: 불필요한 fallback 정리 (선택)

`parts/page-hero.php`의 `$modutheme_hero_defaults['about']` 항목은 이제 사용되지 않음.
- 즉시 제거하지 않고 **주석 처리**만 수행 (다른 페이지에서 아직 사용 중일 수 있음)
- about 페이지는 이제 블록 패턴이 100% 담당

### Phase 6: 검증 체크리스트

| # | 검증 항목 | 통과 기준 |
|---|---|---|
| 1 | about 페이지 블록 에디터 로드 | WP 관리자 > 교회소개 > 편집 시 히어로/소개/예배시간 블록이 시각적으로 표시 |
| 2 | 패턴 삽입 가능 | 블록 인서터 > 패턴 탭에 `hero-about-01`, `about-intro-01`, `worship-times-01` 노출 |
| 3 | 프론트 렌더링 | `/about` 접속 시 기존과 동일한 HTML 구조 + 동일한 스타일 출력 |
| 4 | 반응형 | 375px / 768px / 1440px에서 레이아웃 깨짐 없음 |

| 7 | about-intro 패턴 이동 | 블록 에디터에서 about-intro 블록을 히어로 아래에서 다른 위치로 드래그 이동 가능 |
